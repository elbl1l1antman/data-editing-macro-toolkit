# 데이터 편집 매크로 툴킷 1.1.52

## 주요 변경

- 텍스트 숫자 변환과 수식 빈값 정리가 취소되거나 오류가 나면 변경 전 값으로 복구합니다.
- 시트 통합은 임시 시트에서 결과를 완성한 뒤 기존 결과 시트를 교체합니다.
- 대량 시트 통합 원본을 500행 배열 배치로 읽고 기록하며 진행률 화면 갱신 빈도를 최적화했습니다.
- XLSM과 XLAM을 같은 최신 VBA 및 UserForm에서 생성하고, 모든 배포 파일에서 API 인증정보를 제거합니다.
- 배포 전에 전체 VBA 모듈과 생성 UserForm을 비대화형으로 로드하는 컴파일 스모크 테스트를 실행합니다.

## 사용 방법

기존 리본 메뉴와 실행 방법은 동일합니다. API 기능을 처음 사용하는 PC에서는 해당 기능의 `인증키 설정` 버튼으로 자신의 키를 등록합니다.

## 수정된 문제

- 작업 취소 후 일부 셀만 변경된 상태로 남을 수 있던 문제를 우선 위험 기능에서 보완했습니다.
- 시트 통합 실패 시 기존 통합 결과 시트를 먼저 지워 복구하기 어려웠던 문제를 수정했습니다.
- 최신 XLSM이 XLAM보다 이전 코드를 포함할 수 있던 배포 경로를 통합했습니다.
- 전체 결과를 메모리에 한꺼번에 올리거나 행마다 화면을 다시 그리던 대량 처리 부담을 줄였습니다.

## 주의사항

- 원본 시트에 ID를 생성하는 통합 옵션은 성공 시 원본을 수정합니다. 오류가 발생하면 기존 ID 값 또는 삽입 열을 복구합니다.
- API 인증정보는 배포 파일에 포함되지 않으며 Windows 사용자별로 설정해야 합니다.
- VBA 프로젝트 암호 보호는 임의 편집을 어렵게 하지만 강력한 암호화 수단은 아닙니다.
