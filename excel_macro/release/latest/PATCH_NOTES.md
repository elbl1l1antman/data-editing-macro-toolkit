# 데이터 편집 매크로 툴킷 1.1.49

## 주요 변경

- 주소 첫 어절의 17개 광역시도 표기를 축약형과 정규형 사이에서 변환하는 기능을 추가했습니다.
- 강원·전북·제주는 최신 특별자치도 명칭과 기존 명칭을 모두 입력값으로 인정합니다.
- 축약형을 정규형으로 바꿀 때 최신 명칭 또는 기존 명칭을 버튼으로 선택할 수 있습니다.

## 사용 방법

1. `주소/검색 > 광역시도 표기 변환` 또는 리본의 `광역시도 표기`를 실행합니다.
2. 주소가 들어 있는 한 개 열을 선택합니다.
3. `축약형 → 정규형` 또는 `정규형 → 축약형`을 선택합니다.
4. 정규형으로 변환하는 경우 최신 명칭 또는 기존 명칭을 선택합니다.
5. 원본 오른쪽에 생성된 결과 열을 확인합니다.

## 수정된 문제

- 주소 정규화 과정에서 첫 어절이 아닌 주소 중간의 지명까지 바뀔 수 있던 문제를 수정했습니다.
- `강원도/강원특별자치도`, `전라북도/전북특별자치도`, `제주도/제주특별자치도`를 같은 지역으로 인식하도록 보완했습니다.

## 주의사항

- 주소의 첫 어절이 17개 광역시도 명칭과 정확히 일치할 때만 변환합니다.
- 원본 주소는 변경하지 않고 오른쪽 새 열에 결과를 만듭니다.
- 첫 어절이 아닌 건물명이나 도로명에 포함된 지역명은 변환하지 않습니다.
