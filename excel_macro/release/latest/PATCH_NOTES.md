# 데이터 편집 매크로 툴킷 1.2.1

## 주요 변경

- 값 정리 리본에 `오류값/0 지우기` 버튼을 추가했습니다.
- 선택 범위의 `#N/A`, `#VALUE!`, `#REF!`, `#DIV/0!` 등 모든 Excel 오류값과 숫자 `0`이 있는 셀 내용을 한 번에 지웁니다.
- 오류값과 숫자 0의 처리 건수를 나눠 완료 메시지에 표시합니다.

## 사용 방법

1. 오류값과 숫자 0을 정리할 범위를 선택합니다.
2. `데이터 툴킷 > 값 정리 > 오류값/0 지우기`를 누릅니다.
3. 확인창의 대상 범위를 확인하고 실행합니다.

## 수정된 문제

- 필터나 찾기 기능으로 오류값 종류를 하나씩 찾아 지워야 했던 반복 작업을 줄였습니다.
- 작업 취소 또는 실행 오류가 발생하면 선택 범위를 변경 전 상태로 복구합니다.

## 주의사항

- 셀 내용만 지우며 행과 열은 삭제하지 않습니다.
- 수식 결과가 오류 또는 숫자 0이면 해당 수식도 지워집니다.
- 문자열 `"0"`, 빈셀, 일반 텍스트, 0이 아닌 숫자는 유지합니다.
