# 데이터 편집 매크로 툴킷 1.1.51

## 주요 변경

- 네이버 주소 검증 첫 팝업의 업체명·주소 선택 흐름을 실제 동작과 일치하도록 개편했습니다.
- 업체명과 주소 체크박스가 검색 방식과 후속 범위 선택 대상을 함께 결정합니다.

## 사용 방법

1. `네이버 지역검색 > 주소 검증`을 실행합니다.
2. 첫 팝업에서 `업체명 범위 사용`, `주소 범위 사용` 중 필요한 항목을 체크합니다.
3. 첫 행 헤더, 후보 수, 요청 간격과 정렬 방식을 설정하고 `실행`을 누릅니다.
4. 체크한 항목의 Excel 범위 선택창에서 실제 데이터 범위를 지정합니다.
5. 두 항목을 체크한 경우 업체명 범위 다음에 주소 범위를 선택합니다.

## 수정된 문제

- 첫 팝업의 빈 입력칸과 `선택 안내` 버튼이 실제 범위를 선택하지 않아 사용법을 오해하게 만들던 문제를 수정했습니다.
- 체크박스와 검색 방식 드롭다운이 서로 다른 조합을 가질 수 있던 중복 설정을 제거했습니다.
- UserForm 버튼과 안내문이 폼 영역 밖으로 잘리지 않는지 자동 검사합니다.

## 주의사항

- 업체명과 주소를 함께 사용할 때 두 범위는 같은 시트에 있고 행 수가 같아야 합니다.
- 실제 범위 선택은 첫 팝업을 닫은 뒤 열리는 Excel 범위 선택창에서 수행합니다.
- 범위 선택창에서는 마우스, 방향키 조합 또는 직접 주소 입력을 사용할 수 있습니다.
