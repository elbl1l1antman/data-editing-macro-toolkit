# 데이터 편집 매크로 툴킷 1.2.5

## 주요 변경

- 전화번호 정리 작업을 500행 단위 배열 처리로 변경했습니다.
- Excel 셀을 번호마다 반복해서 읽고 쓰는 횟수를 줄여 대량 자료의 처리 속도를 개선했습니다.

## 사용 방법

1. 기존과 같이 `데이터 툴킷 > 값 정리 > 전화번호 정리`를 실행합니다.
2. 정리할 전화번호 범위를 선택하고 필요한 옵션을 지정합니다.
3. 대량 범위는 자동으로 500행씩 처리되므로 사용자가 범위를 나눌 필요가 없습니다.
4. 진행률 창에서 현재 처리 상태를 확인하거나 `작업 취소`를 누를 수 있습니다.

## 수정된 문제

- 전화번호마다 Excel 셀을 개별적으로 읽고 쓰면서 대량 자료 처리 시간이 길어지던 문제를 개선했습니다.
- 진행률을 셀마다 갱신해 Excel과 UserForm 사이의 호출이 과도하게 발생하던 구조를 청크 단위로 변경했습니다.

## 주의사항

- 수식 셀은 기존과 같이 정리 대상에서 제외됩니다.
- 수식이 섞인 500행 청크는 수식 보존을 위해 변경된 일반 셀만 개별 기록하므로, 모든 셀이 일반 값인 범위보다 처리 속도가 느릴 수 있습니다.
- 작업 취소는 현재 처리 중인 최대 500행 청크가 끝난 뒤 반영됩니다.
