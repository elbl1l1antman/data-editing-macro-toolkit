# 데이터 편집 매크로 툴킷 1.1.48

## 주요 변경

- 모집단에서 층화 기준을 선택해 계통 표본을 추출하는 마법사를 추가했습니다.
- 층별 원표본과 대체표본을 함께 추출할 수 있으며, 대체표본 배수는 기본 3배에서 사용자가 조정할 수 있습니다.
- 현재 행 순서 유지, 오름차순, 내림차순 중 추출 전 정렬 방식을 선택할 수 있습니다.
- 표본설계 할당 결과가 있으면 층별 목표 표본수를 자동으로 연결하고, 없으면 사용자가 직접 입력할 수 있습니다.

## 사용 방법

1. 데이터 툴킷의 표본설계 메뉴에서 `표본 추출`을 실행합니다.
2. 모집단 범위와 헤더 포함 여부를 지정합니다.
3. ID 열, 층화 기준 열, 층별 목표 표본수 또는 표본설계 결과 연결 방식을 선택합니다.
4. 대체표본 배수와 정렬 방식, 난수 시드를 확인한 뒤 검토 화면에서 실행합니다.
5. 생성된 결과 시트에서 원표본과 대체표본 구분, 층별 추출 간격과 표본오차 검토값을 확인합니다.

## 수정된 문제

- 배포 과정에서 생성되는 표본 추출 UserForm의 구문 오류를 수정했습니다.
- 헤더가 없는 단일 행 데이터도 범위로 인식하도록 보완했습니다.
- 검토 화면에서 모집단 수와 층별 설정이 누락되지 않도록 수정했습니다.

## 주의사항

- 표본오차는 단순임의추출 가정을 사용한 검토용 근사값이며, 복합 표본설계의 최종 추정오차를 대신하지 않습니다.
- 원본 시트는 수정하지 않고 별도 결과 시트를 만듭니다.
- 같은 데이터와 같은 난수 시드를 사용하면 동일한 추출 결과를 재현할 수 있습니다.
