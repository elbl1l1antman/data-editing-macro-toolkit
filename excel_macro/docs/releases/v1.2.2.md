# 데이터 편집 매크로 툴킷 1.2.2

## 주요 변경

- 전화번호 검수에서 동일 숫자 연속 반복의 위험 단계를 세분화했습니다.
- 짧은 숫자 블록 반복과 순차 숫자를 오류 패턴으로 추가했습니다.

## 사용 방법

1. `데이터 툴킷 > 명부 검증 > 전화번호 검사`를 실행합니다.
2. 검수할 전화번호 범위를 선택합니다.
3. 원본 오른쪽에 생성된 `전화번호 유형`과 `전화번호 유효성` 열을 확인합니다.

## 수정된 문제

- 국번이 포함된 번호에서 동일 숫자가 길게 반복되어도 모두 같은 등급으로 표시되던 문제를 수정했습니다.
- `1212`, `2323`, `456456`, `12341234`처럼 일부 숫자 묶음이 반복되는 번호를 정상으로 판정하던 문제를 수정했습니다.

## 주의사항

- 동일 숫자 5회 연속은 실제 번호일 가능성을 고려해 `확인 필요`로 표시합니다.
- 동일 숫자 6회 이상, 2~4자리 숫자 블록 반복, 가입자 번호 전체의 오름차순·내림차순 배열은 `오류`로 표시합니다.
- 전화번호 정리 창의 선택 옵션인 `같은 숫자 4개 이상 반복 시 확인 필요로 대체`는 정리 기능에만 적용되며, 검수 결과의 판정 기준과 구분됩니다.
