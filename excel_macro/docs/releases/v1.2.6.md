# 데이터 편집 매크로 툴킷 1.2.6

## 주요 변경

- 기업/사업체명 정리, 텍스트 숫자 변환, 전화번호·사업자번호 숫자만 추출을 500행 단위 배열 처리로 변경했습니다.
- 기업명 정리에 사용하는 정규식을 매 셀마다 만들지 않고 Excel 세션 동안 재사용합니다.
- 복수 대표번호 탐색과 결과 기록에서 셀별 Excel 접근을 제거했습니다.

## 사용 방법

1. 기존과 같이 리본에서 필요한 정리 기능을 실행합니다.
2. 처리할 범위를 선택하고 기존 옵션을 지정합니다.
3. 대량 범위는 자동으로 500행씩 처리되므로 사용자가 범위를 나눌 필요가 없습니다.
4. 진행률 창에서 처리 상태를 확인하거나 작업을 취소할 수 있습니다.

## 수정된 문제

- 대량 기업명 정리에서 같은 정규식 객체를 수만 번 생성하던 반복 비용을 제거했습니다.
- 숫자 변환과 구분기호 제거가 셀마다 Excel을 호출해 처리 시간이 길어지던 구조를 개선했습니다.
- 전화번호 정규화 전에 수행하는 복수 대표번호 탐색이 대량 범위를 두 번 셀별 순회하던 문제를 개선했습니다.

## 주의사항

- 정리 규칙과 출력 형식은 이전 버전과 같습니다.
- 수식 셀은 변경하지 않습니다. 수식이 섞인 청크는 수식 보존을 위해 변경된 일반 셀만 기록합니다.
- 작업 취소는 현재 처리 중인 최대 500행 청크가 끝난 뒤 반영됩니다.
