# 층화 계통 표본추출 설계

## 목적

표본설계에서 계산한 층별 최종할당을 모집단 명부에 연결하고, 층화 계통추출로 원표본과 대체표본을 선정한다. 통계 지식이나 매크로 사용 경험이 없는 사용자도 준비, 설정, 검토, 실행 순서를 화면만 보고 이해할 수 있어야 한다.

대상 버전은 `1.1.48`이다.

## 사용자 성공 기준

- 사용자는 모집단 데이터 범위와 ID 열을 직접 선택할 수 있다.
- 성별, 지역, 업종, 규모 등 복수 열을 층화 기준으로 선택할 수 있다.
- 기존 `표본설계_할당결과`를 자동 연결하거나 층별 목표 원표본 수를 직접 입력할 수 있다.
- 현재 행 순서를 기본으로 사용하되 정렬 열과 오름차순·내림차순을 선택할 수 있다.
- 기본 3배인 대체표본 수를 사용자가 조절할 수 있다.
- 실행 전에 층별 모집단수, 목표표본, 추출간격, 대체표본 가능 수, 승수, 표본오차와 경고를 확인할 수 있다.
- 원본 시트는 수정하지 않고 결과와 검토 시트를 새로 생성한다.
- 같은 난수 시드를 다시 사용하면 같은 입력과 설정에서 같은 결과가 생성된다.

## 범위

### 포함

- 복수 층화 변수의 AND 조합으로 층 생성
- 층별 목표 원표본 수 자동 연결 및 직접 수정
- 층별 선형 계통추출
- 원표본과 복수 차수 대체표본의 중복 없는 선정
- 포함확률, 승수, 유한모집단 보정 표준오차와 표본오차 계산
- 설정, 층별 요약, 추출 결과, 경고 및 난수 시드 기록
- 진행률과 즉시 취소 요청 처리

### 제외

- PPS 계통추출
- 다단계·집락 표본추출
- 복합표본설계의 엄밀한 분산 추정
- 비응답 조정, 사후층화, 림가중, 가중치 절삭
- 원본 모집단 시트의 정렬 또는 값 변경

## 통계 기준

층 `h`에서 모집단수는 `N_h`, 목표 원표본 수는 `n_h`로 정의한다.

- 원표본 추출간격: `K_h = N_h / n_h`
- 무작위 시작점: `0 <= u_h < K_h`
- 추출 위치: `Floor(u_h + j * K_h) + 1`, `j = 0 ... n_h - 1`
- 포함확률: `pi_h = n_h / N_h`
- 승수: `w_h = N_h / n_h`
- 유한모집단 보정 표준오차: `SE_h = Sqrt(((N_h - n_h) / (N_h - 1)) * p * (1 - p) / n_h)`
- 표본오차: `MOE_h = z * SE_h`

기본값은 신뢰수준 95%, 예상비율 `p=0.5`이다. 신뢰수준과 예상비율은 사용자가 변경할 수 있다. `n_h=N_h`이면 표준오차와 표본오차는 0으로 처리한다.

계통표본에는 일반적으로 불편 분산추정량이 없으므로 표본오차는 단순임의추출 근사치로 명시한다. 정렬된 명부에 계통추출을 적용하면 실제 분산은 이 근사치와 다를 수 있으며, 결과와 매뉴얼에 이 제한을 표시한다.

참고 기준:

- Statistics Canada, Probability sampling: https://www150.statcan.gc.ca/n1/edu/power-pouvoir/ch13/prob/5214899-eng.htm
- Statistics Canada, Survey Methods and Practices: https://www150.statcan.gc.ca/n1/pub/12-587-x/12-587-x2003001-eng.pdf

## 추출 알고리즘

각 층은 독립적으로 처리한다.

1. 원본 행 순서를 유지하거나 사용자가 지정한 열로 층 내부 행을 정렬한다.
2. 목표 원표본 수를 `Min(n_h, N_h)`로 확정한다.
3. 전체 층 명부에서 원표본을 계통추출하고 선택 행을 잔여 명부에서 제외한다.
4. 대체 차수별로 잔여 명부에서 `Min(n_h, 잔여수)`개를 새 시작점으로 계통추출한다.
5. 직전 차수까지 선정된 행은 이후 차수에서 제외한다.
6. 대체표본은 같은 층의 원표본 추출순번과 순서대로 연결한다.
7. 잔여 모집단이 부족하면 가능한 수만 선정하고 검토 시트에 부족 수를 기록한다.

대체배수 기본값은 `3`이며 0부터 사용자가 조절할 수 있다. 원표본과 대체표본은 어떤 차수에서도 중복되지 않는다.

## 목표표본 연결

### 자동 연결

- `표본설계_할당결과`에서 `최종할당` 열과 쿼터 차원 열을 탐지한다.
- 사용자가 선택한 층화 열과 같은 이름의 할당결과 열을 정규화된 헤더명으로 연결한다.
- 층화 값은 공백을 정리한 텍스트의 완전 일치로 연결한다.
- 같은 층 조합이 여러 행이면 `최종할당`을 합산한다.
- 미매칭 층은 실행 대상에서 제외하지 않고 검토 단계에서 목표표본 직접 입력을 요구한다.

### 직접 지정

- 검토 목록에서 층을 선택하고 목표 원표본 수를 입력한 뒤 적용한다.
- 자동 연결값도 같은 방식으로 수정할 수 있다.
- 목표값이 비어 있거나 음수, 소수이면 실행을 차단한다.
- 0은 해당 층을 추출하지 않는 명시적 설정으로 인정한다.

## 3단계 UserForm

### 1단계: 모집단과 층 만들기

화면 상단에 다음 안내를 표시한다.

> 모집단의 헤더와 데이터를 함께 선택하세요. 원본은 수정하지 않으며 결과 시트를 새로 만듭니다.

구성:

- `모집단 범위 선택` 버튼과 선택 주소 표시
- `첫 행을 헤더로 사용` 체크박스, 기본 선택
- ID 열 드롭다운과 `ID가 없으면 결과용 ID 자동 생성` 선택
- 층화 열 다중선택 목록
- 자동 감지 결과: 데이터 행 수, ID 공란·중복 수, 선택한 층화 열, 생성 예상 층 수
- `다음` 버튼은 범위와 층화 열이 유효할 때만 진행

범위 선택 버튼은 Excel 범위 선택창을 사용해 마우스, 주소 직접 입력, 방향키, `Shift`, `Ctrl+Shift` 선택을 모두 지원한다.

### 2단계: 목표표본과 추출 설정

구성:

- 목표표본 출처: `표본설계_할당결과 자동 연결` / `직접 지정`
- 대체표본 배수: 기본 3, 최소 0
- 정렬 방식: `현재 행 순서 유지` / `오름차순` / `내림차순`
- 정렬 열 드롭다운은 오름차순·내림차순일 때만 활성화
- 신뢰수준: 기본 95%
- 예상비율: 기본 0.5
- 난수 시드: 비우면 자동 생성, 숫자를 입력하면 재현 가능
- 결과 시트명: 기본 `표본추출_결과`
- 각 입력 옆에 한 줄 설명과 허용 범위를 표시

### 3단계: 실행 전 검토

층별 목록에 다음 항목을 표시한다.

- 층 번호와 층화 값
- 모집단수
- 목표 원표본
- 요청 대체표본
- 실제 가능한 대체표본
- 원표본 추출간격
- 포함확률
- 승수
- 표본오차
- 상태 및 경고

목표표본 직접 수정 영역은 선택한 층, 현재 목표값, 새 목표값, `적용` 버튼으로 구성한다. `실행 가능`, `확인 필요`, `실행 불가`를 텍스트로 표시하며 색상에만 의존하지 않는다.

## 결과 시트

`표본추출_결과`는 원본 선택 열을 모두 복사하고 오른쪽에 다음 관리 열을 추가한다.

- `__SAMPLE_SOURCE_SHEET`
- `__SAMPLE_SOURCE_ROW`
- `__SAMPLE_ID`
- `__SAMPLE_STRATUM_ID`
- `__SAMPLE_STRATUM_KEY`
- `__SAMPLE_TYPE`: 원표본 또는 대체표본
- `__SAMPLE_REPLACEMENT_ROUND`: 원표본은 0
- `__SAMPLE_LINKED_ORIGINAL_ORDER`
- `__SAMPLE_WITHIN_STRATUM_ORDER`
- `__SAMPLE_INTERVAL`
- `__SAMPLE_RANDOM_START`
- `__SAMPLE_INCLUSION_PROBABILITY`
- `__SAMPLE_WEIGHT`
- `__SAMPLE_STANDARD_ERROR`
- `__SAMPLE_MARGIN_OF_ERROR`
- `__SAMPLE_CONFIDENCE_LEVEL`
- `__SAMPLE_EXPECTED_PROPORTION`
- `__SAMPLE_RANDOM_SEED`

원표본을 먼저 배치하고 대체표본은 차수별로 이어서 배치한다. 자동 ID는 `시트명_R원본행번호` 형식으로 결과에만 기록한다.

## 검토 시트

`표본추출_검토`에는 실행 설정과 층별 집계표를 기록한다.

- 입력 시트와 범위
- 층화 열과 정렬 설정
- 목표표본 출처
- 대체배수
- 신뢰수준, 예상비율, 난수 시드
- 층별 모집단수, 목표·실제 원표본, 목표·실제 대체표본
- 간격, 포함확률, 승수, 표준오차, 표본오차
- 할당 미매칭, 모집단 부족, ID 문제, 대체표본 부족 경고
- 계통표본 표본오차가 단순임의추출 근사치라는 주석

## 진행률과 취소

- 실행 즉시 기존 진행률 UserForm을 표시한다.
- 층별 원표본 및 대체 차수 처리 후 진행률과 현재 층을 갱신한다.
- `작업 취소` 요청은 현재 처리 단위 직후 반영한다.
- 결과는 배열에 모은 뒤 시트에 일괄 기록한다.
- 취소되면 불완전한 결과 시트를 삭제하고 원본은 그대로 둔다.

## 오류 처리

실행 차단 조건:

- 모집단 범위 또는 헤더가 없음
- 층화 열을 선택하지 않음
- 직접 목표표본이 미입력·음수·소수
- 신뢰수준이 0 초과 100 미만이 아님
- 예상비율이 0 초과 1 미만이 아님
- 선택한 정렬 열을 찾지 못함

경고 후 실행 가능한 조건:

- ID 공란 또는 중복: 결과용 자동 ID 사용을 권고
- 목표표본이 모집단보다 큼: 원표본을 모집단수로 제한
- 대체표본 부족: 가능한 수만 추출
- 자동 할당 미매칭: 목표값을 직접 입력할 때까지 검토 단계 유지

## 테스트 기준

- 같은 시드와 입력에서 결과가 완전히 동일하다.
- 층마다 원표본 수가 `Min(목표표본, 모집단수)`와 같다.
- 원표본과 모든 대체 차수 사이에 원본행 중복이 없다.
- 충분한 모집단에서는 각 대체 차수가 원표본 목표 수와 같다.
- 부족한 모집단에서는 가능한 수만 추출되고 경고가 생성된다.
- 현재 순서, 오름차순, 내림차순 결과가 설정대로 달라진다.
- 자동 할당 연결과 직접 목표 수정이 모두 작동한다.
- 승수, 표준오차, 표본오차가 기준 계산값과 일치한다.
- 취소 시 원본과 완성 결과 시트가 남지 않는다.
- 한글 UI 인코딩, 버튼 잘림, 보호된 XLAM 로드와 리본 버튼을 확인한다.

## 배포 규칙

- 버전은 `1.1.48`로 올린다.
- 사용자 매뉴얼에 준비 데이터, 3단계 실행법, 산식과 한계를 추가한다.
- 한글이 포함된 PowerShell 파일은 UTF-8 BOM을 유지한다.
- 최신·버전 XLAM의 VBA 프로젝트 보호를 검증한다.
- 버전 보관본 API 키 제거 정책을 유지한다.
