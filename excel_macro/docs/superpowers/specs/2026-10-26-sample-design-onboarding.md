# 표본설계 예시 기반 사용 유도

## 범위와 흐름
- 기존 설정 마법사와 배분 알고리즘은 유지한다. 새 시트 `표본설계_예시`에서 자료 형태와 다음 작업을 안내한다.
- 예시는 산업·대분류·지역별 모집단 1,000 / 500 / 300개와 목표 180개, 단순 비례로 구성한다. 한 행이 한 쿼터 조합이라는 점과 개별 명부를 그대로 붙여넣으면 안 된다는 점을 설명한다.
- `기본 예시로 연습하기`는 고정된 예시 설정과 자료를 입력 시트에 채운다. 기존 입력 시트가 있으면 기본값 '아니요'인 확인을 받는다. 결과 계산은 별도 `할당 계산` 버튼으로 사용자가 실행한다.
- `실제 자료 입력하기`는 기존 입력 시트로 이동한다. 실제 입력용 리스트/집계표 시트에는 가상 모집단 숫자를 넣지 않는다. 집계표 예시가 실제 데이터로 계산되는 혼동도 방지한다.
- 설정 시트 생성은 기존 입력·집계표·결과·검토 시트를 초기화하지 않는다. 기존 설정이 있는 경우 그대로 유지됨을 알린다.
- 예시와 입력 시트에 이동 링크/계산 버튼을 배치하고 안내 문구는 고정 폭에서 줄바꿈한다. Excel 추가 기능 파일명을 포함한 OnAction으로 매크로를 연결한다.

## 검증과 배포
- 별도 Excel 인스턴스에서 예시 행/실제 입력 공란/사용자 지정 쿼터/버튼 연결/링크/안내 영역을 확인한다.
- 기본 예시의 단순 비례 결과가 100 / 50 / 30, 합계 180이 되는지 실제 VBA 계산으로 검증한다.
- UTF-8, 한국어 PowerShell BOM, 새 VBA 문자열 CP949 변환, 보호 XLAM/XLSM 및 회귀 테스트를 확인한다.
- 1.2.7 사용성 개선으로 배포한다. 미완료 자료 가져오기 기능과 기타 사용자 변경은 제외한다.
