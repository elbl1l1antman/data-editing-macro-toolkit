# 표본설계 계산 및 UX 설계

대상 버전: `1.1.23`

## 목적

표본설계 기능은 모집단 구성표 또는 리스트형 모집단 자료를 기준으로 목표 표본을 쿼터 셀에 배분한다. 계산은 리스트형 데이터를 기준으로 통일하고, 집계표형 입력은 리스트화 후 계산한다.

## 배분 원칙

1. 목표표본 그룹표가 있으면 그룹표를 우선한다.
2. 그룹표가 비어 있으면 전체 목표 표본수 `B4` 하나로 전체 모집단을 배분한다.
3. 그룹 조건은 비어 있지 않은 쿼터값의 AND 조건으로 매칭한다.
4. 여러 그룹에 동시에 매칭되면 조건 수가 많은 그룹을 우선한다.
5. 어떤 그룹에도 매칭되지 않은 모집단 행은 할당에서 제외하고 검토 시트에 경고를 남긴다.

## 배분 방식

- 단순 비례: `모집단수`
- 제곱근 비례: `SQRT(모집단수)`
- 멱배분: `모집단수^alpha`
- 균등 배분: `1`
- 사용자 지정 가중: `사용자가중치`, 없으면 모집단수

이론할당은 `그룹목표표본수 x 배분가중치 / 그룹가중치합`으로 계산한다. 최종할당은 이론할당의 정수부를 먼저 배정하고, 잔차가 큰 셀부터 남은 표본을 더해 목표합계에 맞춘다.

## 검토 기준

- `표본설계_할당결과`에는 배분기준값, 배분가중치, 그룹가중치합, 이론할당, 잔차, 최종할당을 표시한다.
- `표본설계_검토`에는 목표그룹별 목표표본수, 최종할당, 차이, 행 수를 표시한다.
- 최소표본/최대표본 제약 때문에 목표합계와 최종할당 합계가 맞지 않을 수 있다. 이 경우 `합계불일치` 경고를 남긴다.

## UX 원칙

- 사용자는 먼저 설계 시트 생성 또는 구성표 리스트화로 입력 구조를 만든다.
- 매출액, 종사자 수, 인구수처럼 실제 값으로 들어온 열은 `구간 만들기`로 구간 변수를 생성한 뒤 쿼터로 사용한다.
- 구간 만들기는 선택 숫자 열 오른쪽에 새 구간 열을 삽입한다.
- 구간 설정은 통합문서 내 `_SampleDesignBandSettings` 숨김 시트에 임시 저장해 같은 통합문서에서 재사용한다.
- 구간 조건은 시작값 `초과/이상`, 종료값 `미만/이하`를 각각 명시하게 한다.
