# 데이터 편집 매크로 툴킷 사용자 메뉴얼

대상 버전: `1.1.22`

이 문서는 Excel 추가기능 `DataEditingMacroToolkit_latest.xlam`을 설치한 사용자가 리본 메뉴에서 각 기능을 실행하는 방법을 정리합니다. 기능이 추가되거나 동작이 바뀌면 이 문서도 함께 갱신합니다.

## 설치와 업데이트

설치 파일:

`release/latest/DataEditingMacroToolkit_latest.xlam`

설치 경로:

Excel > 파일 > 옵션 > 추가 기능 > Excel 추가 기능 > 이동 > 찾아보기

설치 후 Excel 상단 리본의 `보기` 탭 옆에 `데이터 툴킷` 탭이 표시됩니다.

업데이트할 때는 기존 추가기능을 해제한 뒤 최신 `DataEditingMacroToolkit_latest.xlam`을 다시 등록합니다. 같은 파일명으로 덮어쓴 경우 Excel을 완전히 종료했다가 다시 실행하는 편이 안전합니다.

## 기본 사용 원칙

- 원본 데이터는 가능하면 별도 파일로 보관합니다.
- 열을 새로 만드는 기능은 대부분 선택 범위 오른쪽에 결과 열을 추가합니다.
- 삭제, 재구성, 통합처럼 구조를 바꾸는 기능은 결과 시트를 새로 만드는 방식을 우선 사용합니다.
- 범위 선택 창에서는 마우스 드래그, 직접 주소 입력, `Ctrl+Shift+방향키`, `Shift+방향키`를 사용할 수 있습니다.
- API를 쓰는 기능은 인증키 설정을 먼저 실행합니다.
- 작업 행이 많으면 진행률 창이 표시됩니다. 작업 중 Excel이 잠시 느려질 수 있으므로 완료 메시지가 뜰 때까지 기다립니다.

## 리본 메뉴 구성

`데이터 툴킷` 탭은 다음 그룹으로 구성됩니다.

- `값 정리`
- `사업자등록`
- `네이버 지역검색`
- `데이터 통합`
- `SPSS 표 정리`
- `명부 품질`
- `이상치 탐지`
- `표본설계`
- `정보`

## 값 정리

### 숫자 변환

텍스트로 저장된 숫자를 실제 숫자 형식으로 변환합니다.

사용 흐름:

1. 변환할 범위를 선택합니다.
2. `값 정리 > 숫자 변환`을 실행합니다.
3. 선택 범위 안에서 숫자로 해석 가능한 값을 실제 숫자로 바꿉니다.

`시트 숫자 변환`은 현재 시트의 실제 데이터 영역만 대상으로 실행합니다. 빈 행/열까지 전체 시트를 처리하지 않습니다.

### 전화번호 정리

혼재된 전화번호를 표준 형태로 정리합니다. 원본을 직접 바꾸지 않고 오른쪽에 복사본 열을 만든 뒤 정리합니다.

지원 예:

- 일반 지역번호
- 휴대전화
- 대표번호
- 0507 등 네이버 안심번호 계열

`전화번호 숫자만`은 대시가 있는 번호에서 숫자만 남긴 복사본 열을 만듭니다.

### 기업명 정리

사업체명/기업체명에서 분석에 방해되는 표현을 정리합니다.

주요 정리 대상:

- `(주)`, `주식회사`, `유한회사`, `Co., Ltd.` 등 회사형태 표현
- 괄호와 특수문자
- 본점, 지점, 지사, 영업소, 000점 같은 사업장 구분 표현
- 영어 단어의 한글 발음 변환
- 알파벳 읽기 변환

사용 흐름:

1. 기업명 범위를 선택합니다.
2. `값 정리 > 기업명 정리`를 실행합니다.
3. 옵션 창에서 적용할 정리 규칙을 선택합니다.
4. 오른쪽 결과 열에서 정리 결과를 확인합니다.

### 주소 유형 판별/주소 체계 분리/주소 통합

`주소 유형 판별`은 주소가 도로명주소인지 법정/행정동 기준 주소인지 판별합니다.

`주소 체계 분리`는 주소 범위 오른쪽에 다음 2개 열을 만듭니다.

- 동 기준 주소
- 도로명주소

`주소 통합`은 이미 분리된 주소 열을 우선순위에 따라 하나의 통합주소 열로 합칩니다.

## 사업자등록

### 인증키 설정

공공데이터포털 국세청 사업자등록정보 API 인증키를 저장하거나 변경합니다.

### 3열 병합

사업자등록번호가 3개 열로 나뉘어 있을 때 `000-00-00000` 형식의 한 열로 합칩니다.

### 상태조회

선택한 사업자등록번호 범위를 API로 조회하고, 사용자가 체크한 반환값만 열로 추가합니다.

사용 흐름:

1. `사업자등록 > 인증키 설정`을 먼저 실행합니다.
2. 사업자등록번호 범위를 선택합니다.
3. `사업자등록 > 상태조회`를 실행합니다.
4. 반환받을 항목을 체크합니다.
5. 결과 열이 선택 범위 오른쪽에 추가됩니다.

## 네이버 지역검색

### 인증키 설정

네이버 Developers의 Client ID와 Client Secret을 저장합니다.

### 신규 리스트

업종과 지역 기준으로 네이버 지역검색 API를 호출해 신규 업체 리스트를 만듭니다.

주요 옵션:

- 행정동 기준 또는 법정동 기준
- 광역시도/시군구 필터
- 검색 업종
- 검색 결과 수와 호출 지연

### 주소 검증

기존 명부의 업체명 또는 주소를 기준으로 네이버 지역검색 결과를 조회하고 검증 등급을 만듭니다.

검증 등급:

- 정상
- 오류 위험성 낮음
- 오류 위험성 보통
- 오류 위험성 높음 확인 필요

## 데이터 통합

여러 시트의 데이터를 같은 헤더 기준으로 하나의 시트에 쌓습니다.

사용 흐름:

1. `데이터 통합 > 통합 표시행`으로 통합할 열 위에 표시값을 입력할 행을 만들 수 있습니다.
2. 통합할 열 위 표시행에 `x`, `1`, `●` 등 아무 값을 입력합니다.
3. `데이터 통합 > 시트 통합`을 실행합니다.
4. 통합할 시트, 헤더 행, ID 처리 방식, 결과 시트명을 지정합니다.
5. 시트별 헤더 매칭 결과를 확인하고 실행합니다.

ID가 없는 시트는 결과 시트에서 자동 ID를 만들 수 있습니다. 필요하면 원본 시트에 ID 열을 생성하는 옵션도 선택할 수 있습니다.

`통합 시트 분리`는 통합 결과의 관리코드를 기준으로 원본 시트별 데이터를 다시 나눕니다.

## SPSS 표 정리

SPSS에서 내보낸 집계표 작업을 보조합니다.

주요 기능:

- 목차 생성
- 표/배너 재구성
- 세로 배너 삭제
- 표 메타 추출

`표/배너 재구성`은 원본 시트를 복사한 뒤 삭제할 표와 배너, 배너 순서를 반영해 새 집계표 시트와 목차 시트를 만듭니다.

`세로 배너 삭제`는 BOT/TOP/MID 계열 세로형 배너 행을 삭제하는 별도 기능입니다.

## 명부 품질

### 검증 시트

명부 검증용 표준 입력 시트를 만듭니다.

표준 헤더:

- ID
- 사업체명
- 기업체명
- 이름
- 연락처1
- 연락처2
- 연락처3
- 주소1
- 주소2
- 주소3
- 이메일
- 직무
- 직책
- 소속부서
- 기타정보

사용 방식:

1. `빈 표준 입력 시트 만들기`: 표준 헤더만 있는 시트를 만들고 사용자가 데이터를 붙여넣습니다.
2. `기존 명부 자동 인식해서 구성`: 헤더가 있는 원본 명부 범위를 선택하면 자동으로 표준 시트를 만듭니다.

자동 인식 결과는 실행 전에 요약으로 표시됩니다. 인식이 잘못된 경우 취소하고 원본 헤더명을 더 명확히 수정한 뒤 다시 실행합니다.

### 품질 진단

빈값, 전화번호 유효성, 사업자번호 유효성, 주소 유형 등을 요약한 리포트 시트를 만듭니다.

자동 탐지와 수동 선택을 모두 지원합니다.

### 중복 탐지

업체명, 주소, 전화번호, 사업자번호를 조합해 중복 의심 쌍과 점수를 생성합니다.

업체명은 다음 기준을 반영합니다.

- 표준화명 일치
- 한쪽 이름이 다른 쪽 이름에 포함
- 3자 이상 공통 접두어

### 업체명 매칭

업체명 표준화명과 유사그룹 열을 만듭니다.

## 이상치 탐지

선택한 숫자 범위에서 Q1/Q3, IQR 기준으로 이상치를 확인합니다.

실행 전 확인:

- 이상치 탐지는 통계적으로 의심되는 값을 표시하는 보조 도구입니다.
- 가능한 경우 먼저 2차 자료 대체, 전년도 자료 대체, 원자료 또는 응답자 재확인처럼 실제 확인 가능한 대체 절차를 검토합니다.
- `분석 열 선택` 실행 시 사전 확인 팝업이 표시됩니다.

작업 시트 사용:

1. 사전 확인 팝업에서 `예`를 선택하면 `이상치탐지_작업` 시트가 생성됩니다.
2. 원본 데이터에서 대체가 필요한 후보만 필터링합니다.
3. 작업 시트에 `ID`, `업종`, `매출액 규모`, `종사자 규모`, `대체대상_원값` 등 검토에 필요한 열을 붙여넣습니다.
4. 대체 대상 숫자 열의 헤더와 데이터 범위를 선택합니다. 예: `E14:E500`
5. 다시 `분석 열 선택`을 실행하거나, 팝업에서 계속 진행해 범위를 지정합니다.

사용 흐름:

1. 이상치 확인 대상 범위를 선택합니다.
2. 범위 검증 창에서 헤더와 값 구조를 확인합니다.
3. 기초통계량표가 원본 데이터에서 떨어진 위치에 생성됩니다.
4. 선택 범위 오른쪽에 Q1/Q3 기준값 열과 검토용 복사 열이 생성됩니다.
5. 이상치 후보에는 조건부 서식이 적용됩니다.
6. 검토용 복사 열에서 필요한 값만 직접 수정하거나 기준값을 참고해 대체합니다.

## 표본설계

### 설계 시트 생성

표본설계 입력 시트를 만듭니다.

입력 방식:

- 리스트형 입력
- 집계표형 입력

목표 표본수, 배분 방식, 사용할 쿼터 변수를 GUI에서 선택할 수 있습니다.

### 구성표 리스트화

모집단 집계표를 표본설계 계산용 리스트형 데이터로 변환합니다.

선택 방식:

1. `자동 감지 후 미리보기`: 선택 범위 안에서 표 제목, 행축, 가로축, 값 영역을 자동 탐지합니다.
2. `범위 직접 지정 후 미리보기`: 행축 데이터 범위, 가로 헤더 범위, 값 영역을 사용자가 직접 선택합니다.

탐지 또는 지정된 구조는 UserForm 미리보기 창에 표시됩니다. 구조가 맞으면 실행하고, 맞지 않으면 취소 후 범위를 다시 선택합니다.

### 할당 계산

`표본설계_입력` 시트를 기준으로 표본을 배분합니다.

지원 방식:

- 단순 비례
- 제곱근 비례
- 멱배분
- 균등
- 사용자 지정 가중

결과 시트에는 목표그룹, 그룹목표표본수, 배분가중치, 그룹가중치합, 이론할당, 잔차, 최종할당이 표시됩니다.

### 리스트→집계표

리스트화 결과 또는 할당결과를 다시 집계표 형태로 변환합니다.

### 진행률 관리표

할당결과를 기반으로 회수, 부족, 초과, 달성률을 관리하는 시트를 만듭니다.

## 정보

`모든 시트 A1 선택`은 모든 워크시트의 선택 셀을 A1로 맞춥니다.

`버전 정보`는 현재 설치된 툴킷 버전과 주요 기능을 표시합니다.

## 문제 해결

### 리본 탭이 보이지 않음

Excel 추가 기능 목록에서 `DataEditingMacroToolkit_latest.xlam`이 체크되어 있는지 확인합니다. 그래도 보이지 않으면 Excel을 완전히 종료한 뒤 다시 실행합니다.

### 매크로 실행이 차단됨

Excel 보안 설정에서 매크로 실행이 허용되어야 합니다. 회사 보안 정책이 있는 경우 신뢰할 수 있는 위치에 파일을 두어야 할 수 있습니다.

### 범위 선택이 어렵거나 선택 창이 취소됨

범위 선택 창에서 직접 주소를 입력할 수 있습니다.

예:

- `A:A`
- `B1:B100`
- `A1:H500`

### API 기능이 실패함

인증키가 설정되어 있는지 확인합니다. 네트워크 연결, API 제공기관의 호출 제한, 인증키 만료도 확인해야 합니다.

### 대량 데이터에서 Excel이 느려짐

진행률 창이 표시되면 작업이 진행 중인 상태입니다. 완료 메시지가 뜰 때까지 기다립니다. 다른 프로그램으로 전환하거나 Excel 창을 반복 클릭하면 응답 지연이 더 길어질 수 있습니다.

## 메뉴얼 관리 원칙

기능을 추가하거나 기존 기능의 사용 흐름이 바뀌면 다음 항목을 함께 갱신합니다.

- `docs/USER_MANUAL.md`: 사용자 실행 방법과 주의사항
- `README.md`: 현재 기능 목록과 설치/배포 요약
- `src/MacroToolkit.bas`: `TOOLKIT_VERSION`
- `release/latest`: 최신 배포 산출물

릴리스 커밋 전 확인:

- 새 버튼 또는 메뉴명이 메뉴얼에 반영되어 있는지 확인
- 새 UserForm의 입력 항목과 결과 위치가 메뉴얼에 반영되어 있는지 확인
- API 인증키, 원본 변경, 대량 처리 같은 주의사항이 필요한지 확인
- `git diff --check` 실행
- 기능 변경이면 `publish_release.ps1` 실행
