# 데이터 편집 매크로 툴킷 사용자 메뉴얼

대상 버전: `1.1.35`

이 문서는 Excel 추가기능 `DataEditingMacroToolkit_latest.xlam`을 설치한 사용자가 리본 메뉴에서 각 기능을 실행하는 방법을 정리합니다. 기능이 추가되거나 동작이 바뀌면 이 문서도 함께 갱신합니다.

## 설치와 업데이트

설치 파일:

`release/latest/DataEditingMacroToolkit_latest.xlam`

설치 경로:

Excel > 파일 > 옵션 > 추가 기능 > Excel 추가 기능 > 이동 > 찾아보기

설치 후 Excel 상단 리본의 `보기` 탭 옆에 `데이터 툴킷` 탭이 표시됩니다.

업데이트할 때는 기존 추가기능을 해제한 뒤 최신 `DataEditingMacroToolkit_latest.xlam`을 다시 등록합니다. 같은 파일명으로 덮어쓴 경우 Excel을 완전히 종료했다가 다시 실행하는 편이 안전합니다.

API 인증키가 필요한 기능은 인증키 설정 버튼으로 현재 Windows 사용자 설정에 저장합니다. 개발/배포 과정에서는 `release/latest` 최신본만 로컬 인증키 저장 상태를 유지할 수 있고, `release/v*` 버전별 보관본은 저장 전 워크북 내부 API 키 저장소를 정리합니다. 외부 공유나 백업 기준 파일은 버전별 `release/v*` 산출물을 사용합니다.

## 기본 사용 원칙

- 원본 데이터는 가능하면 별도 파일로 보관합니다.
- 열을 새로 만드는 기능은 대부분 선택 범위 오른쪽에 결과 열을 추가합니다.
- 삭제, 재구성, 통합처럼 구조를 바꾸는 기능은 결과 시트를 새로 만드는 방식을 우선 사용합니다.
- 범위 선택 창에서는 마우스 드래그, 직접 주소 입력, `Ctrl+Shift+방향키`, `Shift+방향키`를 사용할 수 있습니다.
- API를 쓰는 기능은 인증키 설정을 먼저 실행합니다.
- 작업 시간이 긴 기능은 진행률 창이 표시됩니다. 중단하려면 진행률 창의 `작업 취소`를 누릅니다.
- 취소는 현재 처리 중인 셀, 행, 비교 묶음, API 요청이 끝난 직후 반영됩니다. 이미 처리된 결과는 원본 보존 방식이 아닌 기능에서는 일부 남을 수 있습니다.

## 리본 메뉴 구성

`데이터 툴킷` 탭은 다음 그룹으로 구성됩니다.

- `값 정리`
- `사업자등록`
- `네이버 지역검색`
- `데이터 통합`
- `SPSS 표 정리`
- `명부 품질`
- `이상치 탐지`
- `표본설계`
- `정보`

## 값 정리

### 숫자 변환

텍스트로 저장된 숫자를 실제 숫자 형식으로 변환합니다.

사용 흐름:

1. 변환할 범위를 선택합니다.
2. `값 정리 > 숫자 변환`을 실행합니다.
3. 선택 범위 안에서 숫자로 해석 가능한 값을 실제 숫자로 바꿉니다.

`시트 숫자 변환`은 현재 시트의 실제 데이터 영역만 대상으로 실행합니다. 빈 행/열까지 전체 시트를 처리하지 않습니다.

### 전화번호 정리

혼재된 전화번호를 표준 형태로 정리합니다. 원본을 직접 바꾸지 않고 오른쪽에 복사본 열을 만든 뒤 정리합니다.

지원 예:

- 일반 지역번호
- 휴대전화
- 대표번호. `15881222`처럼 8자리만 있는 값도 `1588-1222` 형식으로 정리합니다.
- 0507 등 네이버 안심번호 계열

정리 옵션:

- `앞자리가 0이 아니면 0을 붙인 후 정리`: Excel이 선행 0을 떨어뜨린 지역번호/휴대폰 번호를 먼저 보정합니다.
- `같은 숫자 4개 이상 반복 시 번호 대신 확인 필요 입력`: `02-231-4444`처럼 실제 번호일 수도 있지만 임의 입력 가능성이 있는 값을 결과 열에 `확인 필요`로 표시합니다.
- `8자리 값을 휴대폰 개인전화 010-XXXX-XXXX 형식으로 정리`: 8자리 값이 대표번호가 아니라 휴대폰 뒷자리인 경우 사용합니다.

`02-123-4567`, `1234-5678`처럼 가입자번호가 단순 연속 숫자인 값은 오류 패턴으로 보고 정리 결과에서 빈값으로 삭제합니다.

`전화번호 숫자만`은 대시가 있는 번호에서 숫자만 남긴 복사본 열을 만듭니다.

### 기업명 정리

사업체명/기업체명에서 분석에 방해되는 표현을 정리합니다.

주요 정리 대상:

- `(주)`, `주식회사`, `유한회사`, `Co., Ltd.` 등 회사형태 표현
- 괄호와 특수문자
- 괄호와 괄호 안 문구. 예: `(도서출판)용용드래곤` -> `용용드래곤`, `（도）봄` -> `봄`
- 본점, 지점, 지사, 영업소, 000점 같은 사업장 구분 표현
- 영어 단어의 한글 발음 변환
- 알파벳 읽기 변환

`괄호·특수문자 제거`를 켜도 `A4시스템`, `3S테크`처럼 한글/영문/숫자가 섞인 기업명은 숫자만 남기지 않고 이름 문자를 보존합니다.
괄호 안 설명 문구 자체를 없애려면 옵션 창에서 `괄호 안 문구까지 삭제`를 선택합니다.
`영어 단어 한글 발음`과 `알파벳 읽기`를 함께 켜면 영어 단어 한글 발음을 먼저 적용합니다. 예를 들어 `AIsystem`은 `AI`와 `system`을 나눠 `에이아이시스템`으로 정리하고, 사전에 없는 남은 약어만 알파벳 읽기로 처리합니다.
영어 단어 사전은 IT, 금융, 부동산, 의료, 교육, 제조, 물류, 식음료, 문화/관광, 생활서비스 계열에서 자주 보이는 단어를 우선 포함합니다.

사용 흐름:

1. 기업명 범위를 선택합니다.
2. `값 정리 > 기업명 정리`를 실행합니다.
3. 옵션 창에서 적용할 정리 규칙을 선택합니다.
4. 오른쪽 결과 열에서 정리 결과를 확인합니다.

### 주소 유형 판별/주소 체계 분리/주소 통합

`주소 유형 판별`은 주소가 도로명주소인지 법정/행정동 기준 주소인지 판별합니다.

`주소 체계 분리`는 주소 범위 오른쪽에 다음 2개 열을 만듭니다.

- 동 기준 주소
- 도로명주소

`주소 통합`은 이미 분리된 주소 열을 우선순위에 따라 하나의 통합주소 열로 합칩니다.

## 사업자등록

### 인증키 설정

공공데이터포털 국세청 사업자등록정보 API 인증키를 저장하거나 변경합니다.

### 3열 병합

사업자등록번호가 3개 열로 나뉘어 있을 때 `000-00-00000` 형식의 한 열로 합칩니다.

### 상태조회

선택한 사업자등록번호 범위를 API로 조회하고, 사용자가 체크한 반환값만 열로 추가합니다.

사용 흐름:

1. `사업자등록 > 인증키 설정`을 먼저 실행합니다.
2. 사업자등록번호 범위를 선택합니다.
3. `사업자등록 > 상태조회`를 실행합니다.
4. 반환받을 항목을 체크합니다.
5. 결과 열이 선택 범위 오른쪽에 추가됩니다.

## 네이버 지역검색

### 인증키 설정

네이버 Developers의 Client ID와 Client Secret을 저장합니다.

### 신규 리스트

업종과 지역 기준으로 네이버 지역검색 API를 호출해 신규 업체 리스트를 만듭니다.

주요 옵션:

- 행정동 기준 또는 법정동 기준
- 광역시도/시군구 필터
- 검색 업종
- 검색 결과 수와 호출 지연

### 주소 검증

기존 명부의 업체명 또는 주소를 기준으로 네이버 지역검색 결과를 조회하고 검증 등급을 만듭니다.
옵션창에서는 업체명/주소 사용 여부와 검색 방식을 먼저 선택합니다.
실행 후 업체명 범위와 주소 범위 선택창이 차례대로 열리며, 이 선택창에서는 마우스 드래그뿐 아니라 `Shift+방향키`, `Ctrl+Shift+방향키`, 직접 주소 입력을 사용할 수 있습니다.

검증 등급:

- 정상
- 오류 위험성 낮음
- 오류 위험성 보통
- 오류 위험성 높음 확인 필요

### 공식몰 링크 검색

업체명/기업체명 범위를 선택하면 네이버 웹문서 API로 `업체명 공식몰`을 검색하고 선택 범위 오른쪽에 결과 열을 추가합니다.

생성 열:

- 공식몰 검색어
- 공식몰 후보 URL
- 후보 제목
- 후보 도메인
- 판정등급
- 판정근거
- 제외/검토 URL
- 제외/검토 사유
- 검색일시

판정 기준:

- `정상`, `가능성 높음`: 자체 도메인 또는 자체 쇼핑몰 구조로 보이는 후보입니다.
- `확인 필요`: 자체 도메인 후보는 있으나 장바구니, 결제, 상품 페이지 등 쇼핑 기능 단서가 부족합니다.
- `공식몰 없음`: 검색 결과에서 자체 쇼핑몰 후보를 찾지 못했습니다.
- `조회 실패`: API 오류, 네트워크 오류, 인증키 오류 등으로 조회하지 못한 행입니다.

네이버 브랜드스토어, 스마트스토어, 네이버쇼핑, 쿠팡, 11번가, G마켓, 옥션, SSG, 롯데온 등 오픈마켓/입점몰은 공식 채널일 수 있어도 자체 공식몰로 인정하지 않습니다. 해당 결과는 `제외/검토 URL`과 `제외/검토 사유`에 기록됩니다.

## 데이터 통합

여러 시트의 데이터를 같은 헤더 기준으로 하나의 시트에 쌓습니다.

사용 흐름:

1. `데이터 통합 > 통합 표시행`으로 통합할 열 위에 표시값을 입력할 행을 만들 수 있습니다.
2. 통합할 열 위 표시행에 `x`, `1`, `●` 등 아무 값을 입력합니다.
3. `데이터 통합 > 시트 통합`을 실행합니다.
4. 통합할 시트, 헤더 행, 결과 KEY 헤더명, ID 처리 방식, 결과 시트명을 지정합니다.
5. KEY 열을 헤더명으로 자동 매칭할지, 시트별로 직접 지정할지 선택합니다.
6. `KEY 열 직접 지정`을 켠 경우 각 원본 시트에서 KEY로 사용할 열을 한 개씩 선택합니다.
7. 시트별 헤더 매칭 결과와 KEY 열 위치를 확인하고 실행합니다.

ID가 없는 시트는 결과 시트에서 자동 ID를 만들 수 있습니다. 필요하면 원본 시트에 ID 열을 생성하는 옵션도 선택할 수 있습니다.
시트마다 KEY 열 이름이 다르거나 헤더 행 구조가 불안정하면 `KEY 열 직접 지정`을 사용하는 편이 안전합니다.

`통합 시트 분리`는 통합 결과의 관리코드를 기준으로 원본 시트별 데이터를 다시 나눕니다.

## SPSS 표 정리

SPSS에서 내보낸 집계표 작업을 보조합니다.

주요 기능:

- 목차 생성
- 표/배너 재구성
- 세로 배너 삭제
- 표 메타 추출

`표/배너 재구성`은 원본 시트를 복사한 뒤 삭제할 표와 배너, 배너 순서를 반영해 새 집계표 시트와 목차 시트를 만듭니다.

`세로 배너 삭제`는 BOT/TOP/MID 계열 세로형 배너 행을 삭제하는 별도 기능입니다.

## 명부 품질

### 검증 시트

명부 검증용 표준 입력 시트를 만듭니다.

표준 헤더:

- ID
- 사업체명
- 기업체명
- 이름
- 연락처1
- 연락처2
- 연락처3
- 주소1
- 주소2
- 주소3
- 이메일
- 직무
- 직책
- 소속부서
- 기타정보

사용 방식:

1. `빈 표준 입력 시트 만들기`: 표준 헤더만 있는 시트를 만들고 사용자가 데이터를 붙여넣습니다.
2. `기존 명부 자동 인식해서 구성`: 헤더가 있는 원본 명부 범위를 선택하면 자동으로 표준 시트를 만듭니다.

기존 명부 자동 구성에서는 ID/KEY 열을 직접 지정할 수 있습니다. 직접 지정하지 않으면 헤더명 자동 인식 결과를 사용하고, ID 열이 없으면 자동 ID를 생성합니다.
자동 인식 결과는 실행 전에 요약으로 표시됩니다. 인식이 잘못된 경우 취소하고 원본 헤더명을 더 명확히 수정하거나 ID/KEY 열 직접 지정을 사용한 뒤 다시 실행합니다.

### 품질 진단

빈값, 전화번호 유효성, 사업자번호 유효성, 주소 유형 등을 요약한 리포트 시트를 만듭니다.

자동 탐지와 수동 선택을 모두 지원합니다.
전화번호는 명백한 임시값/영값 패턴을 `전화번호 오류`로, 숫자 길이 이상 또는 같은 숫자가 4번 이상 반복되는 번호를 `전화번호 확인 필요`로 구분합니다.

### 중복 탐지

업체명, 주소, 전화번호, 사업자번호를 조합해 중복 의심 쌍과 점수를 생성합니다.

업체명은 다음 기준을 반영합니다.

- 표준화명 일치
- 한쪽 이름이 다른 쪽 이름에 포함
- 3자 이상 공통 접두어

### 업체명 매칭

업체명 표준화명과 유사그룹 열을 만듭니다.

## 이상치 탐지

선택한 숫자 범위에서 Q1/Q3, IQR 기준으로 이상치를 확인합니다.

실행 전 확인:

- 이상치 탐지는 통계적으로 의심되는 값을 표시하는 보조 도구입니다.
- 가능한 경우 먼저 2차 자료 대체, 전년도 자료 대체, 원자료 또는 응답자 재확인처럼 실제 확인 가능한 대체 절차를 검토합니다.
- `분석 열 선택` 실행 시 사전 확인 팝업이 표시됩니다.

작업 시트 사용:

1. 사전 확인 팝업에서 `예`를 선택하면 `이상치탐지_작업` 시트가 생성됩니다.
2. 원본 데이터에서 대체가 필요한 후보만 필터링합니다.
3. 작업 시트에 `ID`, `업종`, `매출액 규모`, `종사자 규모`, `대체대상_원값` 등 검토에 필요한 열을 붙여넣습니다.
4. 대체 대상 숫자 열의 헤더와 데이터 범위를 선택합니다. 예: `E14:E500`
5. 다시 `분석 열 선택`을 실행하거나, 팝업에서 계속 진행해 범위를 지정합니다.

사용 흐름:

1. 이상치 확인 대상 범위를 선택합니다.
2. 범위 검증 창에서 헤더와 값 구조를 확인합니다.
3. 기초통계량표가 원본 데이터에서 떨어진 위치에 생성됩니다.
4. 선택 범위 오른쪽에 Q1/Q3 기준값 열과 검토용 복사 열이 생성됩니다.
5. 이상치 후보에는 조건부 서식이 적용됩니다.
6. 검토용 복사 열에서 필요한 값만 직접 수정하거나 기준값을 참고해 대체합니다.

## 표본설계

### 설계 시트 생성

표본설계 입력 시트를 만듭니다.

입력 방식:

- 리스트형 입력
- 집계표형 입력

목표 표본수, 배분 방식, 사용할 쿼터 변수를 GUI에서 선택할 수 있습니다.

### 구성표 리스트화

모집단 집계표를 표본설계 계산용 리스트형 데이터로 변환합니다.

선택 방식:

1. `자동 감지 후 미리보기`: 선택 범위 안에서 표 제목, 행축, 가로축, 값 영역을 자동 탐지합니다.
2. `범위 직접 지정 후 미리보기`: 행축 데이터 범위, 가로 헤더 범위, 값 영역을 사용자가 직접 선택합니다.

탐지 또는 지정된 구조는 UserForm 미리보기 창에 표시됩니다. 구조가 맞으면 실행하고, 맞지 않으면 취소 후 범위를 다시 선택합니다.

### 할당 계산

`표본설계_입력` 시트를 기준으로 표본을 배분합니다.

지원 방식:

- 단순 비례
- 제곱근 비례
- 멱배분
- 균등
- 사용자 지정 가중

결과 시트에는 목표그룹, 그룹목표표본수, 배분가중치, 그룹가중치합, 이론할당, 잔차, 최종할당이 표시됩니다.

계산 방식 확인:

- 단순 비례: 모집단수를 그대로 가중치로 사용합니다.
- 제곱근 비례: `SQRT(모집단수)`를 가중치로 사용합니다.
- 멱배분: `모집단수^alpha`를 가중치로 사용합니다.
- 균등: 모든 셀의 가중치를 `1`로 봅니다.
- 사용자 지정 가중: 사용자가 입력한 가중치가 있으면 그 값을 우선 사용합니다.

각 목표그룹 안에서 `그룹목표표본수 x 배분가중치 / 그룹가중치합`으로 이론할당을 계산한 뒤, 잔차가 큰 셀부터 정수 보정합니다. 최소표본/최대표본 제약이 강하면 목표합계와 최종할당 합계가 다를 수 있으므로 `표본설계_검토` 시트의 경고를 확인합니다.

### 숫자값 구간 만들기

매출액, 종사자 수, 인구수처럼 실제 숫자값이 있는 열을 표본설계용 구간 변수로 변환합니다.

사용 흐름:

1. 구간으로 바꿀 숫자 열을 선택합니다. 예: B열의 매출액.
2. `표본설계 > 구간 만들기`를 실행합니다.
3. UserForm에서 결과 열 헤더와 구간 개수를 입력합니다.
4. 구간별 시작값, 종료값, 시작 조건(`초과`/`이상`), 종료 조건(`미만`/`이하`)을 지정합니다.
5. 확인하면 선택 열 오른쪽에 새 구간 열이 생성되고, 각 행에는 `IFS` 수식이 입력됩니다.

예시:

```excel
=IFS(Q4<5,"01. 5인 미만",Q4<10,"02. 5-9명",Q4>=10,"03. 10명 이상")
```

실제 생성 수식도 같은 방식으로 선택한 셀 주소를 직접 참조합니다. 사용자는 생성된 수식을 직접 검토하고 필요한 경우 수정할 수 있습니다.

구간 시작값과 종료값에는 `1,000`, `1,000명`, `75%`처럼 쉼표, 단위, 퍼센트가 포함된 값을 입력할 수 있습니다. 구간 설정은 통합문서 안의 `_SampleDesignBandSettings` 숨김 시트에 임시 저장됩니다. 같은 통합문서에서 다시 실행하면 직전 구간값을 기본값으로 불러옵니다.

### 리스트→집계표

리스트화 결과 또는 할당결과를 다시 집계표 형태로 변환합니다.

### 진행률 관리표

할당결과를 기반으로 회수, 부족, 초과, 달성률을 관리하는 시트를 만듭니다.

## 문제 해결

### 리본 탭이 보이지 않음

Excel 추가 기능 목록에서 `DataEditingMacroToolkit_latest.xlam`이 체크되어 있는지 확인합니다. 그래도 보이지 않으면 Excel을 완전히 종료한 뒤 다시 실행합니다.

### 매크로 실행이 차단됨

Excel 보안 설정에서 매크로 실행이 허용되어야 합니다. 회사 보안 정책이 있는 경우 신뢰할 수 있는 위치에 파일을 두어야 할 수 있습니다.

### 범위 선택이 어렵거나 선택 창이 취소됨

범위 선택 창에서 직접 주소를 입력할 수 있습니다.

예:

- `A:A`
- `B1:B100`
- `A1:H500`

### API 기능이 실패함

인증키가 설정되어 있는지 확인합니다. 네트워크 연결, API 제공기관의 호출 제한, 인증키 만료도 확인해야 합니다.

### 대량 데이터에서 Excel이 느려짐

진행률 창이 표시되면 작업이 진행 중인 상태입니다. 중단하려면 `작업 취소`를 누릅니다.

취소 요청은 현재 처리 단위가 끝난 뒤 반영됩니다. API 기능은 이미 전송된 HTTP 요청 자체를 강제로 끊지는 않으므로, 현재 요청이 끝난 뒤 다음 행으로 넘어가기 전에 중단됩니다.

다른 프로그램으로 전환하거나 Excel 창을 반복 클릭하면 응답 지연이 더 길어질 수 있습니다.

## 메뉴얼 관리 원칙

기능을 추가하거나 기존 기능의 사용 흐름이 바뀌면 다음 항목을 함께 갱신합니다.

- `docs/USER_MANUAL.md`: 사용자 실행 방법과 주의사항

- 새 UserForm의 입력 항목과 결과 위치가 메뉴얼에 반영되어 있는지 확인
- API 인증키, 원본 변경, 대량 처리 같은 주의사항이 필요한지 확인
- `git diff --check` 실행
- 기능 변경이면 `publish_release.ps1` 실행
