# 데이터 편집 매크로 툴킷 변경 이력

이 문서는 Git 이력, 기존 사용자 메뉴얼, 릴리스별 패치노트를 기준으로 복원한 통합 변경 이력입니다. 별도 배포 기록이 확인되지 않는 버전 번호는 생략했습니다.

## 1.2.3
- 통신사 대표번호 접두어 15종을 등록하고 8자리 휴대폰 변환 옵션보다 우선 처리하도록 변경했습니다.
- `1588-12345`, `1588-1234~5` 같은 복수 대표번호를 두 결과 열로 분할하고 검수 시 `대표번호 복수 확인 필요`로 표시합니다.
