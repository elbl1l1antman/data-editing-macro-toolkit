## 프로젝트 구조

- `src/`: VBA 원본 소스입니다. 기능 수정은 여기서 먼저 합니다.
- `dev/`: 개발/검토용 `.xlsm` 통합문서입니다.
- `data/`: 외부 공개자료에서 추출한 보조 사전 등 생성 데이터입니다. 원본 대용량 파일은 저장소에 포함하지 않습니다.
- `release/`: 버전별 배포 산출물입니다.
- `scripts/`: 빌드와 퍼블리시 자동화 스크립트입니다.
- `docs/USER_MANUAL.md`: 사용자 메뉴얼입니다. 기능 추가나 사용 흐름 변경 시 함께 갱신합니다.
- `docs/sample_design_calculation_spec.md`: 표본설계 배분 방식과 검토 기준 설계 문서입니다.

## 배포 정책

앞으로 실제 설치/배포 파일은 `.xlam`을 기준으로 합니다.

- `.xlam`: Excel 추가 기능 설치용 파일입니다. 사용자는 이 파일을 설치합니다.
- `.xlsm`: 개발/검토용 통합문서입니다. 설명 시트와 소스 미리보기를 확인할 때 사용합니다.
- `.bas`: Git에서 관리하는 VBA 원본 소스입니다.
- API 인증키는 기본적으로 Windows 사용자 설정(`SaveSetting/GetSetting`)에 저장되며 Git 소스나 버전별 릴리스에 넣지 않습니다.
- `release/latest`와 `release/v*`의 모든 산출물은 저장 전에 워크북 내부 API 키/토큰/자격증명 저장소를 자동 정리합니다.
- API 인증정보는 배포 파일이 아니라 각 Windows 사용자의 `SaveSetting/GetSetting` 저장소에만 유지합니다.

## 현재 기능

- 텍스트 형식 숫자를 실제 숫자값으로 변환. 대량 범위는 500행 배열 청크로 처리
- 현재 시트의 실제 데이터 영역만 대상으로 텍스트 숫자 일괄 변환
- 혼재된 한국 전화번호 형식 정규화. 첫 숫자 묶음이 실제 4자리인 050X 계열 안심번호와 통신사 대표번호 접두어 15종을 표준 형식으로 인식하며, 대량 범위는 500행 배열 청크로 처리
- 전화번호 정리 옵션: 선행 0 보정, 4회 이상 반복 숫자 `확인 필요` 대체, 대표번호가 아닌 8자리 개인 휴대폰 `010-XXXX-XXXX` 변환 지원
- `02-123-4567`, `1234-5678`처럼 가입자번호가 단순 연속 숫자인 전화번호는 정리 결과에서 빈값으로 삭제하고 오류 패턴으로 분류
- 전화번호 정리 시 원본 오른쪽에 복사본 열을 생성하고, 9자리 복수 대표번호는 두 결과 열로 분할
- 전화번호 유형 분류 및 유효성 검사. 원본 구분기호를 반영한 050X 안심번호, 대표번호, 복수 대표번호, 영값, 동일 숫자 5회·6회 반복, 반복 블록 및 순차 숫자 오류 조건을 반영
- 전화번호/사업자등록번호의 하이픈 제거 복사본 열 생성
- 사업자등록 상태조회 시 체크박스로 반환받을 값 선택, 모두 포함 선택 지원
- 기업/사업체명 정리: 공백, 회사형태 표기, 괄호·특수문자, 괄호 안 문구, '의 ' 앞부분, 한글/영문 중복 병기 제거, 영어 단어 한글 발음, 알파벳 한글 읽기 규칙을 선택 적용. 특수문자 제거 전에 `+`는 `플러스`, `&`는 `앤`, 독립 표기 `Co.`는 `컴패니`로 치환. 숫자가 섞인 영문 병기와 `FORWARD3DKOREA`, `TVASOFT` 같은 붙임형 영문 병기도 한글 음차와 비교해 중복이면 제거. `SOFT`는 `소프트`, `SOFTWARE`는 `소프트웨어`로 구분. 영어 단어 변환과 알파벳 읽기를 함께 켜면 영어 단어/약어 조합을 먼저 분리해 단어 음차를 우선 적용. 수기 업무 사전과 한국어기초사전 XML에서 추출한 영어 외래어 보조 사전을 함께 사용하며, 옵션창에서 정리 순서 프리셋 또는 체크박스를 누른 순서대로 실행하는 직접 지정 방식을 선택할 수 있음. 대량 범위는 500행 배열 청크와 재사용 정규식으로 처리
- 문자 검진 함수 생성: 선택 범위 오른쪽에 Excel 수식을 생성해 공란, 알파벳 포함, 특수기호 포함, 정상 여부를 행별로 판정
- 업체명 표준화 및 유사그룹 생성
- 명부 검증용 표준 입력 시트 생성 및 기존 명부 헤더 자동 인식 구성
- 기존 명부 자동 구성 시 ID/KEY 열 직접 지정 지원
- 명부 품질 진단 리포트 생성
- 업체명/주소/전화번호/사업자번호 조합 기반 중복 업체 탐지. 업체명은 표준화명 일치, 한쪽 이름 포함, 3자 이상 공통 접두어를 같은 기업 판단 기준에 반영
- 주소 범위 선택 후 도로명주소 또는 법정/행정동 기준 주소 여부 판별
- 주소에서 광역시도, 시군구, 읍면동, 상세주소 분해
- 주소 범위 선택 후 원본 오른쪽에 동 기준 주소와 도로명주소 2개 열 생성

## Excel 추가 기능 설치

Excel에서 다음 경로로 `.xlam` 파일을 설치합니다.

파일 > 옵션 > 추가 기능 > Excel 추가 기능 > 이동 > 찾아보기


설치 후 Excel 상단 리본의 `보기` 탭 옆에 `데이터 툴킷` 탭이 추가됩니다. 기능은 이 탭의 버튼으로 실행합니다.

- `값 정리`: 숫자 변환, 시트 숫자 변환, 수식 빈값 정리, 전화번호 정리, 전화번호 숫자만, 기업/사업체명 정리, 주소 유형 판별, 주소 체계 분리, 주소 통합, 광역시도 표기 변환
- `사업자등록`: 인증키 설정, 번호 숫자만, 3열 병합, 상태조회
- `네이버 지역검색`: 인증키 설정, 행정동/법정동 기준 신규 리스트, 업체명/주소 검증, 업체 검색, 공식몰 링크 검색, 행정동/법정동 마스터 양식 생성
- `데이터 통합`: 시트 통합, 통합 시트 원본별 분리
- `SPSS 표 정리`: 목차 생성, 표/배너 재구성, 세로 배너 삭제
- `명부 품질`: 검증 시트 생성, 품질 진단, 중복 탐지, 업체명 매칭, 행정구역 분해, 전화번호 검사
- `이상치 탐지`: 범위 선택, Q1/Q3 검토열 생성, 설정
- `표본설계`: 구성표 리스트화(자동 감지/범위 직접 지정), 리스트→집계표, 설계 시트 생성, 표본설계 가이드, 숫자값 구간 만들기, 표본할당 계산, 계통 표본추출, 진행률 관리표 생성
- `정보`: 모든 시트 A1 선택, 버전 정보
설치 대상 파일:

`release/latest/DataEditingMacroToolkit_latest.xlam`

## Excel VBA 접근 설정

자동으로 `.bas`를 통합문서에 삽입하려면 Excel에서 다음 옵션이 필요합니다.

파일 > 옵션 > 보안 센터 > 보안 센터 설정 > 매크로 설정 > VBA 프로젝트 개체 모델에 안전하게 액세스할 수 있음

이 옵션이 꺼져 있으면 `.xlsm`에는 실행 가능한 VBA 모듈이 없을 수 있습니다. 이 경우 `src/MacroToolkit.bas`를 VBA 편집기에서 직접 가져오면 됩니다.
