## 프로젝트 구조

- `src/`: VBA 원본 소스입니다. 기능 수정은 여기서 먼저 합니다.
- `dev/`: 개발/검토용 `.xlsm` 통합문서입니다.
- `release/`: 버전별 배포 산출물입니다.
- `scripts/`: 빌드와 퍼블리시 자동화 스크립트입니다.

## 현재 버전

`1.1.12`

버전의 기준은 `src/MacroToolkit.bas`의 `TOOLKIT_VERSION`입니다.

## 배포 정책

앞으로 실제 설치/배포 파일은 `.xlam`을 기준으로 합니다.

- `.xlam`: Excel 추가 기능 설치용 파일입니다. 사용자는 이 파일을 설치합니다.
- `.xlsm`: 개발/검토용 통합문서입니다. 설명 시트와 소스 미리보기를 확인할 때 사용합니다.
- `.bas`: Git에서 관리하는 VBA 원본 소스입니다.

## 현재 기능

- 텍스트 형식 숫자를 실제 숫자값으로 변환
- 현재 시트의 실제 데이터 영역만 대상으로 텍스트 숫자 일괄 변환
- 혼재된 한국 전화번호 형식 정규화
- 전화번호 정리 시 원본 오른쪽에 복사본 열을 생성한 뒤 복사본만 정규화
- 전화번호 유형 분류 및 유효성 검사
- 전화번호/사업자등록번호의 하이픈 제거 복사본 열 생성
- 사업자등록 상태조회 시 체크박스로 반환받을 값 선택, 모두 포함 선택 지원
- 기업체명/사업체명 정리: 공백, 회사형태 표기, '의 ' 앞부분, 영어 단어 한글 발음, 알파벳 한글 읽기 규칙을 선택 적용
- 업체명 표준화 및 유사그룹 생성
- 명부 품질 진단 리포트 생성
- 업체명/주소/전화번호/사업자번호 조합 기반 중복 업체 탐지. 업체명은 표준화명 일치, 한쪽 이름 포함, 3자 이상 공통 접두어를 같은 기업 판단 기준에 반영
- 주소 범위 선택 후 도로명주소 또는 법정/행정동 기준 주소 여부 판별
- 주소에서 광역시도, 시군구, 읍면동, 상세주소 분해
- 주소 범위 선택 후 원본 오른쪽에 동 기준 주소와 도로명주소 2개 열 생성
- 분리된 동 기준 주소와 도로명주소를 우선순위 선택 후 통합주소 열로 재결합
- 네이버 지역검색 API 인증키 설정(Client ID/Client Secret)
- 2024년 10월 기준 행정동 마스터와 별도 법정동 마스터를 내장한 네이버 신규 업체 리스트 생성
- 신규 리스트 생성 시 행정동/법정동 기준 선택 지원
- 내장 행정동/법정동 마스터는 추가기능 내부 `VeryHidden` 시트로 보관되며, 신규 리스트 생성 또는 마스터 양식 생성 시에만 사용
- 현재 통합문서에 `행정동_마스터`, `법정동_마스터` 양식 시트를 생성해 기준표를 사용자가 교체/수정 가능
- 기존 업체명/주소 범위 선택 후 네이버 지역검색 결과, 유사도, 검증등급 열 생성
- 네이버 주소 검증 옵션창에서 업체명만/주소만/업체명+주소 분석 여부와 범위를 한 번에 지정
- 네이버 지역검색/주소 검증/사업자등록 상태조회 API 작업 중 진행률 창과 Excel 상태표시줄 표시
- 여러 시트의 데이터를 KEY와 지정 헤더 기준으로 하나의 통합 시트에 적재
- 시트 통합 시 헤더 행 번호 지정, 자동 탐지, 2행 헤더 구조(헤더변수명/실제 헤더변수) 매칭 지원
- 통합 전 시트별 헤더 행, 마지막 데이터 행, 컬럼 매칭 결과를 UserForm에서 확인
- 통합 시트 1행에 원본시트/원본행/필드 관리코드를 추가해 원본시트별 재분리 지원
- 모든 워크시트의 화면 위치를 A1 기준 최상단으로 정렬
- 모든 워크시트의 선택 셀을 A1로 변경
- 숫자 변환과 전화번호 정리를 UserForm 기반 범위 선택 GUI로 실행
- UserForm 버튼/목록 배치 여백 개선 및 리본 아이콘 누락 점검
- 범위 선택 시 Excel 시트에서 Ctrl+Shift+방향키, Shift+방향키, 마우스 드래그로 선택 후 실행 가능
- 이상치 탐지 및 대체 결과 시트 생성
- 이상치 확인 실행 시 범위 검증 후 기초통계량표를 먼저 생성
- 표 전체 선택 시 숫자형 열 자동 탐지 후 선택 목록 제공
- Q1/Q3 기준값 열, 원본 검토복사 열, 조건부 서식 자동 생성
- SPSS 내보내기 통계표에서 선택한 가로/세로 배너 블록 삭제
- SPSS 목차 링크 기반 표/배너 탐지 후 원본 시트 복사본에서 삭제하고 목차 재생성
- SPSS 표/배너 재구성 목록에서 Shift+클릭 연속 선택 및 Ctrl+클릭 개별 선택 지원
- SPSS 표/배너 삭제 결과에서 표와 표 사이 공백 행을 1개로 자동 정리
- 목차가 없는 SPSS 집계표 시트에서 표 제목을 탐지해 목차 링크 시트 생성

- 업종 x 종사자규모, 지역 x 인구수, 사업체규모 등 여러 행/열 집계표를 자동 탐지하고 미리보기 확인 후 표본설계용 리스트형 데이터로 변환
- 표본설계 입력 시트 생성, 단순 비례/제곱근 비례/멱배분 기반 표본할당 결과 및 검토 시트 생성

## Excel 추가 기능 설치

Excel에서 다음 경로로 `.xlam` 파일을 설치합니다.

파일 > 옵션 > 추가 기능 > Excel 추가 기능 > 이동 > 찾아보기


설치 후 Excel 상단 리본의 `보기` 탭 옆에 `데이터 툴킷` 탭이 추가됩니다. 기능은 이 탭의 버튼으로 실행합니다.

- `값 정리`: 숫자 변환, 시트 숫자 변환, 전화번호 정리, 전화번호 숫자만, 기업명 정리, 주소 유형 판별, 주소 체계 분리, 주소 통합
- `사업자등록`: 인증키 설정, 번호 숫자만, 3열 병합, 상태조회
- `네이버 지역검색`: 인증키 설정, 행정동/법정동 기준 신규 리스트, 업체명/주소 검증, 행정동/법정동 마스터 양식 생성
- `데이터 통합`: 시트 통합, 통합 시트 원본별 분리
- `SPSS 표 정리`: 목차 생성, 표/배너 재구성, 세로 배너 삭제
- `명부 품질`: 품질 진단, 중복 탐지, 업체명 매칭, 행정구역 분해, 전화번호 검사
- `이상치 탐지`: 범위 선택, Q1/Q3 검토열 생성, 설정
- `표본설계`: 구성표 리스트화, 설계 시트 생성, 표본할당 계산, 진행률 관리표 생성
- `정보`: 모든 시트 A1 선택, 버전 정보
설치 대상 파일:

`release/latest/DataEditingMacroToolkit_latest.xlam`

## Excel VBA 접근 설정

자동으로 `.bas`를 통합문서에 삽입하려면 Excel에서 다음 옵션이 필요합니다.

파일 > 옵션 > 보안 센터 > 보안 센터 설정 > 매크로 설정 > VBA 프로젝트 개체 모델에 안전하게 액세스할 수 있음

이 옵션이 꺼져 있으면 `.xlsm`에는 실행 가능한 VBA 모듈이 없을 수 있습니다. 이 경우 `src/MacroToolkit.bas`를 VBA 편집기에서 직접 가져오면 됩니다.
