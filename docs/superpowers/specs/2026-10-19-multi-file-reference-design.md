# 다중 파일 자료 가져오기 통합 개발 명세서

작성일: 2026-10-19
상태: 요구사항 정리 및 구현 전 검토. 제품 코드는 아직 변경하지 않음.

## 목적

기준 명부의 행과 ID를 유지하면서 여러 Excel 파일에서 필요한 열을 가져온다. 파일별로 다른 키와 헤더를 연결하고, 출처 우선순위와 자료 기준일에 따라 항목별로 값을 채택한다. 사용자는 정상 연결 행을 일일이 확인하지 않고 결과의 비고를 필터링하여 예외만 검토한다.

주요 사례는 2026년 명부에 2025년 실적을 붙이거나 같은 연도의 종사자 자료와 연락처 자료를 각각 보충하는 작업이다. 연도 또는 작성자에 따라 ID가 달라질 수 있으므로 ID 일치를 강제하지 않는다.

## 사용자가 확정한 요구사항

- 시작할 때 기업체 기준 또는 사업체 기준을 선택한다.
- 파일마다 ID, MSIT_ID, 사업자등록번호, 전화번호, 업체명 또는 사용자가 선택한 복합 키를 연결 기준으로 지정한다.
- 복합 키는 지역+업체명, 업체명+대표자명 등 사용자가 선택한 모든 열이 일치해야 한다.
- 업체별 수동 승인 절차 없이 먼저 일괄 결합한다.
- 주소는 A파일, 종사자는 B파일 등 항목별로 다른 출처의 값을 사용할 수 있다.
- 검토 근거의 순서는 자료 출처, 최신 자료 여부, 주소·업체명·대표자명, 전화번호, 기타 정보다.
- 특이사항은 결과 시트의 비고 5개 열 안에서 유형별로 기록한다.
- 동일 우선순위에서 후보 값이 다르면 기존 값을 유지한다. 기존 값이 없으면 빈칸으로 두고 비고에 기록한다.

## 구현 담당자의 기본 설계

이 절의 선택은 사용자 개별 지시가 아닌 구현 기본안이다. 기존 Excel VBA 추가기능과 UserForm을 사용하고, 별도 웹 앱이나 Power Query 설정을 요구하지 않는다.

### 범위

새 메뉴 `데이터 통합 > 자료 가져오기`로 제공한다. 기존 `시트 통합`의 행 쌓기 기능은 그대로 둔다. 이번 기능은 기준 행을 보존하는 열 보충 작업이며 행 추가, 기업별 자동 합산, 유사도 기반 자동 연결은 포함하지 않는다.

### 설정 화면

설정은 한 UserForm의 3단계로 구성한다.

1. 기준 자료: 기준 통합문서·시트·범위, 헤더 행, 데이터 시작행, 기업체/사업체 단위, 기준 자료일을 지정한다. 첫 행이 헤더가 아닌 경우와 헤더명/변수명 2행 구조를 지원한다. 기존 인식 결과를 제안하되 범위와 행 번호를 수정할 수 있다.
2. 참조 자료: 파일·시트를 복수 등록하고 각 파일의 헤더·데이터 범위, 출처 이름, 우선순위, 자료 기준일을 지정한다. 연결할 기준 열과 참조 열을 각각 선택하고, 가져올 열을 결과 열과 연결한다. 항목 대응표에서 결과 항목의 `대상연도`와 참조 항목의 `자료연도`를 선택적으로 지정한다. 실적연도는 자료를 확인한 날짜와 다르므로 자료 기준일에서 자동 추정하지 않는다. 열 위치와 헤더가 같을 필요는 없다. 헤더가 중복되면 열 문자와 원래 헤더를 함께 표시한다.
3. 실행 확인: 기준 행 수, 참조 자료 수, 연결 키, 결과 열, 기존 값 처리, 자료 연도 및 비고 열을 요약한다. 실행하면 진행률·취소 창을 표시하고 완료 후 새 결과 시트를 연다.

업체별 후보 선택 화면은 만들지 않는다. 여러 조건을 쓸 때는 키 구성 열을 추가하는 방식으로 제공하며, 조건별 fallback 체인은 첫 구현에서 추가하지 않는다.

### 기업체/사업체 단위

기업체 기준에서도 업체명 접두어 또는 포함 관계만으로 본점·지점을 합치지 않는다. 사용자가 지정한 키로만 연결하며 참조 자료의 단위가 다르면 설정 요약과 `비고_연결`에 표시한다.

사업체 기준에서 사업자등록번호만 선택하여 여러 지점이 연결되면 복수 후보로 기록한다. 주소·지점명 등의 추가 키 사용을 설정 단계에서 안내하되 강제하지 않는다. 어느 기준에서도 종사자 수나 매출을 자동 합산하지 않는다.

### 키와 값의 비교

- 원본은 보존하고 비교용 키만 별도로 만든다. 오류값·빈값을 포함한 키는 매칭하지 않으며 빈 키끼리 연결하지 않는다.
- ID/MSIT_ID: 앞뒤 공백만 제거하고 문자로 비교한다. 선행 0은 유지하며 숫자처럼 보인다는 이유로 숫자로 변환하지 않는다.
- 사업자번호·전화번호: 비교에만 구분기호를 제거한다. 전화번호의 잘못된 패턴을 삭제하거나 휴대폰으로 치환하지 않는다. `+82` 등의 변환은 기존 검증된 비교 헬퍼 중 의미가 일치하는 경우에만 사용한다.
- 업체명·대표자명·지역·주소: 앞뒤 및 중복 공백, 영문 대소문자 차이를 정리한다. 본점·지점 삭제, 부분 일치, 임의 음차, 도로명/지번 상호 동등 판정은 자동 수행하지 않는다.
- 복합 키는 구성 값 길이를 포함한 직렬화 또는 중첩 Dictionary로 만든다. 구분기호가 값에 포함되어도 다른 조합과 충돌해서는 안 된다.
- 결과 값은 참조 파일의 실제 값으로 기록한다. 비교용 키로 사용한 정리 문자열로 원래 결과 값을 덮어쓰지 않는다. 숫자 0은 유효한 값이며 빈값으로 취급하지 않는다.

### 항목별 값 채택

1. 출처 우선순위는 작은 숫자가 우선한다. 같은 우선순위에서는 자료 기준일이 최신인 후보를 먼저 검토한다. 날짜가 없는 자료는 같은 순위의 날짜가 있는 자료 뒤에 두고 비고에 남긴다. 파일 수정일은 자료 기준일을 대신하지 않는다.
2. 기준 행에 연결된 참조 후보를 찾고 가져올 항목마다 독립적으로 채택한다. 해당 항목 값이 빈칸 또는 Excel 오류값이면 사용 가능한 다음 순위 자료를 찾는다. 오류값은 비고에 기록한다.
3. 최상위 출처 순위와 최신 기준일이 같은 후보들의 해당 항목 값이 다르면 자동 채택을 중단한다. 더 낮은 출처에서 임의로 하나를 고르지 않고 기준 명부 값을 유지하며, 그 값도 없으면 빈칸으로 둔다. 주소·업체명·대표자명·전화번호 등의 차이는 비고로 제공하고 숨은 점수로 동률을 해소하지 않는다.
4. 복수 후보라도 값이 모두 같으면 같은 값을 가져올 수 있다. 대표 근거 행은 파일 등록순·시트순·원본행순의 첫 행으로 기록하고 동일값 후보 건수를 이력에 남긴다. 값이 일치하는지 확인하려고 문자열 숫자를 강제 변환하거나 금액 단위를 추정하지 않는다.
5. 초기 기존 값 처리 기본은 `빈값만 보충`이다. 사용자가 `참조값 우선`을 선택하면 위 규칙으로 결정된 참조값이 있을 때만 기존 값을 교체한다. 빈값을 이유로 유효한 기존 값을 지우지 않는다. 두 모드 모두 기존 값과 참조값이 다르면 충돌 사실을 기록한다.
6. 전년도 실적은 `종사자수_2025` 등 별도 결과 열을 기본 제안한다. 대상연도와 자료연도가 모두 있고 다르면 시점 경고를 남긴다. 대상연도만 있고 자료연도가 없으면 `자료연도 미상`으로 표시한다. 대상연도를 지정하지 않은 연락처·주소 등은 연도 차이 경고를 만들지 않는다. 단위와 기준시점이 다른 값을 자동 합산하거나 보정하지 않는다.
7. 기존 수식 셀은 두 기존 값 처리 모드 모두에서 보존하며, 수식 결과가 빈 문자열이어도 덮어쓰지 않는다. 가져올 값이 있는 경우에는 `비고_보충누락`에 `기존 수식 보존: 항목명`을 기록하고 후보값을 이력에 남긴다. 원본의 기존 열과 수식 관계를 유지하기 위해 기준 시트를 임시 결과 시트로 복제하는 경로를 우선 사용한다. 참조 파일의 가져올 값은 수식 자체가 아닌 평가된 값을 사용한다.

### 비고 5개 열

| 열 | 기록 내용 |
|---|---|
| 비고_연결 | 빈 키, 일치 대상 없음, 동일 키 복수 후보, 기업체/사업체 단위 차이 |
| 비고_업체정보 | 업체명·주소·대표자명·전화번호·추가 확인 항목의 차이 |
| 비고_값충돌 | 기존값/후보값 차이, 동률 후보의 상이한 값, 기존값 유지 또는 빈칸 처리 |
| 비고_시점 | 자료 기준일 없음, 요청한 자료연도와 다른 연도에서 보충한 값 |
| 비고_보충누락 | 차순위 출처 보충, 최종 자료 없음, 원본 Excel 오류값 |

동일 항목의 메시지는 중복 제거하고 한 셀 안에서 이어 붙인다. 정상적으로 지정된 출처에서 값이 채택된 사실 자체는 비고가 아니라 이력에 기록한다. 의도적으로 가져온 2025년 실적을 일괄 시점 경고로 표시하지 않는다. 긴 후보 목록은 비고에 건수와 이력 위치를 요약하고 상세 이력에 보존한다.

업체정보 비교 열을 지정하지 않은 경우 해당 항목은 검사하지 않는다. 값이 없으면 다르다고 단정하지 않고 필요한 누락 안내만 남긴다. 키 일치가 업체정보 전체의 일치를 뜻한다고 표시하지 않는다.

### 결과와 출처 기록

- `자료가져오기_결과`: 기준 명부의 행 순서·ID·기존 열을 유지하고 선택한 결과 열과 비고 5개 열을 추가한다. 원본 통합문서와 원본 시트는 변경하지 않는다.
- `자료가져오기_이력`: 기준 파일·시트·원본행·ID, 결과 항목, 기존값, 채택값, 채택/보류/미일치 구분, 출처 파일·시트·원본행·원본ID, 키 구성·조건, 출처 우선순위, 자료 기준일, 충돌 후보, 실행시각을 기록한다. 기준 ID도 중복되거나 없을 수 있으므로 원본행 위치를 함께 사용한다.
- 동률 후보 충돌로 값을 채택하지 못한 경우도 이력에 후보별 근거를 기록한다. 이력이 Excel 시트 행 한도를 넘으면 순번이 붙은 이력 시트로 나누며 자르지 않는다.
- 결과와 이력 시트는 임시 이름으로 생성하고 성공 시에만 최종 이름으로 확정한다. 같은 이름이 이미 있으면 기존 결과를 지우지 않고 새 이름을 부여한다.
- 취소·오류 시 이번 실행에서 만든 임시 시트만 제거하고 사용자 문서와 기존 결과를 보존한다. 화면 갱신·이벤트·자동계산·상태표시줄 설정을 복구한다.

### 속도·설정 재사용

참조 파일은 읽기 전용으로 열고 각 참조 범위를 배열로 읽어 정규화 키별 Dictionary 인덱스를 만든다. 기준 행마다 전체 참조 행을 순회하는 O(n²) 방식은 사용하지 않는다. 전체 참조 파일을 동시에 열어둘 필요는 없다. 이미 사용자가 열어둔 문서는 닫지 않는다.

기준 결과는 500행 단위 배열로 기록하고 진행률·취소를 갱신한다. 동일 키 후보가 과도하면 그 상태와 처리 건수를 표시하며 이력을 누락시키지 않는다. 순회 내부에서는 시트 셀·정규식·헤더 탐색을 반복 생성하지 않는다.

설정은 현재 기준 통합문서의 숨김 설정 시트에 사용자가 `설정 저장`을 선택했을 때만 저장한다. 파일 경로, 헤더 대응, 키 구성, 가져올 항목, 대상연도·자료연도, 우선순위, 자료일과 처리 모드를 저장하고 암호·API 키·원본 데이터 사본은 저장하지 않는다. 다음 실행에서 파일과 헤더가 여전히 존재하는지 재검증한다. 경로가 바뀐 파일은 재지정한다. 첫 구현에서는 과거 실행의 행 연결을 검증 없이 자동 재사용하지 않는다.

## 구현 위치와 순서

1. `src/DatabaseTools.bas`: 기존 시트 선택·헤더 인식·열 연결·임시 결과 시트 처리 중 재사용 가능한 공개 헬퍼를 확인한다. 행 쌓기 함수의 의미를 바꿔 새 동작을 억지로 넣지 않는다. 새 기능 계산은 별도 `src/ReferenceTools.bas`로 구성한다.
2. `scripts/publish_release.ps1`: 기존 UserForm 생성 방식을 따라 3단계 설정 폼과 리본 메뉴를 추가하고 새 모듈을 XLSM/XLAM 양쪽에 포함한다.
3. `src/MacroToolkit.bas`: 통합 실행 메뉴와 리본 콜백에 `자료 가져오기`를 연결하고 공통 진행률·취소·작업 상태 복구 헬퍼를 재사용한다.
4. 테스트: 비교·인덱스·채택·비고 로직을 실제 Excel VBA로 검증하고 임시 통합문서로 결과와 이력을 확인한다.
5. 승인 후 구현 완료 시 버전·사용자 매뉴얼·패치노트와 배포물을 함께 갱신하고 관련 변경만 커밋·푸시한다. 설계 문서만 작성하는 현재 단계에서는 버전이나 릴리스를 변경하지 않는다.

## 인수 검증

- 연도별 ID가 다른 행을 사업자번호·MSIT_ID·전화번호 및 복합 키로 각각 연결한다.
- 빈 키끼리 연결되지 않고, 복합 키의 구분문자가 값에 포함돼도 잘못 연결되지 않는다.
- 파일별 헤더 위치·헤더행·변수명 행이 달라도 지정한 열에서 값을 가져온다.
- 같은 행의 주소는 A자료, 종사자는 B자료로 채택되고 항목별 이력이 정확히 남는다.
- 우선순위가 날짜보다 우선하고, 같은 순위의 최신 자료를 선택하며 날짜 누락을 기록한다.
- 최상위 동률 후보가 다르면 기존 값 유지/기존 공란 시 빈칸 처리하며 차순위로 임의 회피하지 않는다.
- 복수 후보 동일값은 채택하되 복수 후보 표시와 원본 근거가 보존된다.
- 빈값 보충·참조값 우선 모드를 구분하고 숫자 0, 원본 오류, 선행 0 ID를 검증한다. 기존 수식과 빈 문자열을 반환하는 기존 수식이 두 모드에서 모두 보존되고 참조 수식은 값으로 가져오는지 확인한다.
- 기업체/사업체 기준이 다른 자료에서 행 증식·지점 자동 합산·이름 기반 자동 연결이 발생하지 않는다.
- 결과 기준 행 수와 순서가 유지되고 비고 열이 정확히 5개이며, 정상 행은 비고가 비어 있다.
- 충돌·미일치·보충·기준일 누락·연도 차이를 유형별로 기록하고 긴 상세 내용은 이력에서 확인한다.
- 1만 행 이상 기준 자료와 복수 참조 파일로 인덱스 처리, 진행률, 취소, 임시 시트 정리 및 원본 보존을 확인한다.
- 저장한 설정의 파일·헤더가 변경되면 재지정을 유도한다.
- 한글 UTF-8 검사, CP949 VBA 가져오기 컴파일, 보호된 XLSM/XLAM 일치, API 인증정보 제거와 기존 회귀 테스트를 확인한다.
