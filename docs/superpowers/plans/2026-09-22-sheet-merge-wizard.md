# Sheet Merge Wizard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the overloaded sheet-merge setup flow with a three-step wizard that detects sheets and headers, guides ID and column selection, previews mappings, and runs the existing merge engine.

**Architecture:** Keep `DBMerge_BuildPlan`, `DBMerge_WriteMergedSheet`, management codes, and split behavior unchanged. Add small text-based adapters in `MacroToolkit.bas` that serialize detected sheet/header state into the generated UserForm, and let one persistent `frmDatabaseMergeSetup` hide for plan calculation and reopen on its review page.

**Tech Stack:** Excel VBA, MSForms UserForm generated by PowerShell, Excel COM integration tests, PowerShell release tooling.

**Spec:** `docs/superpowers/specs/2026-09-22-sheet-merge-wizard-design.md`

## Global Constraints

- Release version is `1.1.47`.
- Existing merge output columns and `__DBMERGE_*` management codes must not change.
- Existing `통합 시트 분리` behavior must remain compatible.
- `통합 표시행` remains available as an optional advanced feature.
- Default ID mode is output-only automatic ID generation.
- Korean UI text must pass the repository's encoding checks before release.
- Do not stage or remove the user's existing `release/beta-old`, legacy release moves, or unrelated dirty files.

## Review Focus

- A workbook containing hidden/internal sheets should show them but leave them unselected, and must not silently merge them.
- A selected sheet whose header cannot be detected must show `확인 필요` and block preview until a valid header row is supplied.
- Duplicate normalized header names in one sheet must resolve deterministically to the first visible column and show a warning.
- A result sheet name matching a selected source sheet must block preview without discarding the current selections.
- Returning from review to settings must preserve sheet, header, ID, output-name, and advanced-option selections.

```vb
Private mAction As String

Public Property Get Action() As String
    Action = mAction
End Property

Private Sub cmdNext_Click()
    If mpSteps.Value = 0 Then
        If SelectedSheetCount() = 0 Then
            MsgBox "통합할 시트를 하나 이상 선택하세요.", vbExclamation, "시트 데이터 통합"

End Sub
```

- [ ] **Step 3: Replace the linear setup/review calls with one controller loop**

Use one form instance:

```vb
Do
    form.Show
    Select Case LCase$(CStr(form.Action))
        Case "headers"
            form.ConfigureHeaders DBMerge_WizardHeaderInfoText(wb, CStr(form.SelectedSheets), CStr(form.HeaderRowSetting), CStr(form.HeaderMode))
        Case "preview"
            Set plan = DBMerge_BuildPlan(...)
            If Not plan Is Nothing Then
                form.ConfigureReview DBMerge_PlanSummary(plan), DBMerge_MappingSummary(plan), DBMerge_WizardWarningSummary(plan)
            End If
        Case "run"
            Exit Do
        Case Else
            Unload form
            Exit Sub
    End Select
Loop
```

Build `manualKeyColumns` from the form's per-sheet header selections. Do not show the old sequential range pickers in the wizard path.
