# Stratified Systematic Sampling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a novice-friendly three-step wizard that creates strata from a selected population frame and extracts non-overlapping original and replacement samples by linear systematic sampling.

**Architecture:** Keep the feature inside the existing `MacroToolkit.bas` and PowerShell-generated MSForms architecture. VBA owns range parsing, stratum construction, allocation matching, deterministic sampling, review text, and worksheet output; `frmSampleExtractionWizard` only collects settings and guides the user through three pages. Reuse the existing progress/cancel form and release pipeline.

**Tech Stack:** Excel VBA, MSForms UserForm generated by PowerShell, PowerShell static tests and Excel COM smoke tests.

**Spec:** `docs/superpowers/specs/2026-09-22-stratified-systematic-sampling-design.md`

## Global Constraints

- Release version is `1.1.48`.
- Default replacement multiplier is `3`, adjustable to any whole number of `0` or greater.
- Default ordering preserves the current population row order; ascending and descending sort are optional.
- Default error settings are 95% confidence and expected proportion `0.5` with finite population correction.
- Original population worksheets must never be sorted or modified.
- Original and replacement samples must not repeat a source row across any round.
- Systematic-sample margin of error must be labeled as a simple-random-sampling approximation.
- Korean text must pass UTF-8/mojibake checks; Korean PowerShell source must retain UTF-8 BOM.
- Reuse the existing progress/cancel UserForm and array-based worksheet output.
- Do not add dependencies or stage unrelated dirty files.

## Review Focus

- A selected range containing a single data row must produce a valid census result without division by zero.
- Blank stratum values must remain a visible, distinct stratum instead of being silently dropped.
- Numeric and text representations such as `1` and `"1"` must match the allocation result consistently after normalization.
- A requested original plus replacement count larger than the stratum population must produce all available unique rows and a shortage warning.
- A target result sheet name that already exists must be rejected before sampling so no existing user sheet is overwritten.

- [ ] **Step 3: Implement deterministic systematic positions**

Add the minimum core helpers in `MacroToolkit.bas`:

```vb
Private Function SampleExtract_SystematicIndexes(ByVal populationCount As Long, _
                                                 ByVal sampleCount As Long, _
                                                 ByVal randomStart As Double) As Variant
    Dim result() As Long, intervalValue As Double, i As Long
    If populationCount <= 0 Or sampleCount <= 0 Then
        SampleExtract_SystematicIndexes = Array()
        Exit Function
    End If
    If sampleCount > populationCount Then sampleCount = populationCount
    intervalValue = populationCount / sampleCount
    ReDim result(0 To sampleCount - 1)
    For i = 0 To sampleCount - 1
        result(i) = Int(randomStart + (i * intervalValue)) + 1
    Next i
    SampleExtract_SystematicIndexes = result
End Function
```

Clamp `randomStart` to `0 <= start < interval`. For a one-row census, return index `1`, inclusion probability `1`, weight `1`, standard error `0`, and margin of error `0`.

- [ ] **Step 3: Implement the persistent wizard controller**

Use one form instance and an action loop:

```vb
Public Sub SampleExtract_Run()
    Dim wizard As Object, actionName As String
    Set wizard = VBA.UserForms.Add("frmSampleExtractionWizard")
    Do
        wizard.Show
        actionName = LCase$(Trim$(CStr(wizard.Action)))
        Select Case actionName
            Case "pick_range": SampleExtract_PickPopulationRange wizard
            Case "review": SampleExtract_PrepareReview wizard
            Case "run": SampleExtract_Execute wizard: Exit Do
            Case Else: Exit Do
        End Select
    Loop
    Unload wizard
End Sub
```

The range picker uses `Application.InputBox(Type:=8)` and returns to the same form after cancel, preserving current entries. Validate that the selected range belongs to one worksheet and contains at least one data row.
