# KOSIS 모집단 자료 가져오기 개발 명세서

작성일: 2026-11-18
상태: 사용자 검토 승인. API와 실제 통계표 검증 결과에 따라 세부 사항을 보완한다.

## 사용자 검토 확정사항

- 산업분류 11차를 기본 제안하고 10차도 선택할 수 있다. 시점은 사용자가 직접 선택하며 표에 없는 시점은 다른 표로 자동 전환하지 않는다.
- 한 개 또는 여러 시점을 선택한다. 직전 작업은 선택적으로 불러오며, 복원한 시점도 조회 전에 사용자가 명시적으로 확인한다.
- 사업체수와 종사자수는 모두 조회할 수 있으나 표본설계 모집단 지표로는 사용자가 하나를 고른다.
- 산업 선택은 KOSIS의 검색·펼치기·전체 해제 및 상위만, 하위 전체, 최하위 선택 방식을 참고한다. 상위와 하위 또는 전국과 지역을 함께 조회할 수 있으나 중복 합산하지 않고 경고한다.
- 사용자가 행축과 열축을 선택하며 한 축에 복수 분류를 넣을 수 있다. 나머지 조건은 표 블록으로 구분한다.
- 연령구간의 겹침은 차단하고 누락은 경고한다. 원자료의 묶음 연령을 가르는 경계는 차단하고 팝업으로 알린다.
- 추정치·잠정치는 원래 숫자와 부호를 보존하고 검토 시트에 기록한다. 비밀보호·결측은 0으로 치환하거나 불완전 합계를 확정하지 않는다.
- 매 조회마다 리스트·집계표·검토 시트를 새로 만들고 검토 사항을 팝업으로 알린다. 실패한 분할 조회는 완성 결과를 생성하지 않으며 실패 조건을 검토 시트에 기록한다.
- 조회가 끝나면 기존 표본설계 기능을 실행할지만 묻는다. 범위와 지표의 연결은 사용자가 직접 한다. 산업 재분류는 후순위이며 첫 배포 필수 요건이 아니다.
- 키는 사용자가 등록·변경하며 Windows 사용자 설정에 저장한다. 분류정보는 로컬 캐시와 수동 갱신을 제공하고 캐시 시각을 표시한다. 진행 중 취소 시 원본을 보존한다.

## 1. 목적과 범위

Excel 추가 기능에서 KOSIS 모집단 통계의 시점과 분류를 선택하고, 결과를 리스트와 집계표로 생성하여 기존 표본설계에 활용한다. 원본 통계와 결과를 사용자가 확인할 수 있어야 하며 통계의 모집단 적합성이나 표본오차를 자동 보증하지 않는다.

1차 대상:

- 주민등록인구현황 `행정구역(시군구)별/1세별 주민등록인구`: 기관 `101`, 표 `DT_1B04006`.
- 전국사업체조사 `시도·산업·사업체구분별 사업체수, 종사자수`: `DT_1K52D01`, `DT_1K52F01` 후보.
- 전국사업체조사 `시도·산업·종사자규모별 사업체수, 종사자수`: `DT_1K52D03`, `DT_1K52F03` 후보.

사업체 표의 산업분류 개정판과 시점별 제공 범위는 실제 메타자료와 조회 결과로 확정한다. 서로 다른 통계표나 분류를 자동 연결해 시계열로 합치지 않는다. 시도 단위로 제공되는 표에서 시군구 값을 추정하지 않는다.

## 2. 사용자 흐름

리본의 표본설계 영역과 기존 통합 실행 메뉴에 `KOSIS 모집단 가져오기`를 제공한다. 사용자가 이전 작업으로 돌아가 설정을 수정할 수 있는 단계형 UserForm을 사용한다.

1. **자료:** 위 3개 자료 유형 중 선택. 사업체 자료는 제공되는 산업분류 개정판과 표를 명시한다.
2. **시점:** 메타정보에서 실제 제공되는 연도 또는 월을 읽고 사용자가 직접 하나 이상 선택한다. 직전 작업을 불러온 경우에도 복원된 시점을 확인한다.
3. **지역:** 사업체 자료는 전국 합계를 기본 선택한다. 필요하면 표가 제공하는 지역을 복수 선택한다. 주민등록인구는 시도와 시군구를 계층적으로 선택한다.
4. **분류와 항목:** 산업은 코드와 이름이 함께 보이는 계층형 목록에서 검색·펼치기·복수 선택한다. 표에 실제 제공되는 산업 단계만 활성화한다. 사업체구분 또는 종사자규모와 사업체수·종사자수 항목을 선택한다. 인구는 성별과 연령을 선택한다.
5. **연령 구간:** 1세별 값을 유지하거나 사용자가 구간 이름·하한·상한과 경계 포함 여부를 입력한다. 서로 겹치는 구간은 차단하고, 빠진 연령은 경고 후 확인받는다. 원자료의 최상위 묶음 연령은 더 세분화하지 않는다.
6. **출력 구성:** 행축·열축·고정 구분과 값을 선택하고 표본설계에 사용할 구분을 지정한다. 항목이 여러 개면 각각 구분된 표 블록으로 출력한다. 미리보기에서 선택 조건, 예상 요청·셀 수, 합계 중복 및 자료 범위를 보여준다.
7. **조회·검토:** 진행률과 현재 요청 단위, 취소 버튼을 제공한다. 오류·미공표·누락 건수와 합계 검사를 보여준 뒤 새 시트를 만든다.
8. **설계 실행:** 결과를 검토한 후 기존 `집계표로 표본설계` 실행 여부를 묻는다. 범위와 지표는 사용자가 직접 연결하며 기존 설계 결과와 원본은 덮어쓰지 않는다.

전국 합계와 시도 합계, 산업 상위·하위, 전체와 성별 세부 항목을 함께 선택하면 중복 가능성을 명확히 경고한다. 합계를 세부 항목과 함께 다시 합산하지 않으며 사용자가 의도적으로 함께 표시할 때도 별도 값으로 유지한다.

## 3. API 및 보안

- KOSIS 공유서비스의 통계자료·메타자료를 사용한다. 표 선택 방식은 `orgId`, `tblId`, `objL1`~`objL8`, `itmId`, `prdSe`, 시점과 출력 형식을 지정한다.
- 분류와 항목, 상위코드, 단위, 수록시점은 메타정보를 기준으로 조회하고 코드와 표시명을 분리한다. 응답의 통계부호는 `smblChk` 등을 사용해 확인한다.
- 제공받은 가이드의 일반 조회 4만 셀 제한을 넘지 않게 요청을 분할한다. 실제 서비스 응답과 최신 정책을 검증하고, 중복·누락·불완전 응답을 확인하기 전에는 성공으로 표시하지 않는다. 부분 결과를 완성본으로 만들지 않는다.
- HTTPS만 사용하고 시간 제한, 제한 횟수를 둔 재시도, 취소·오류 처리를 구현한다. 요청 대기 중 즉시 중단이 불가능한 경우 이를 표시하고 가능한 빨리 종료한다.
- 인증키 등록·변경은 기존 추가 기능의 사용자별 설정 방식을 따른다. 테스트용 로컬 키 파일은 개발 환경에서만 사용하며 소스, 로그, 오류 메시지, Git, XLSM/XLAM과 버전별 배포물에 포함하지 않는다. API 호출 오류에 URL이나 키를 노출하지 않는다.
- 메타자료 캐시를 사용한다면 기준 표·개정판과 갱신 시각을 보관하고 수동 갱신을 제공한다. 키는 캐시에 저장하지 않는다.

## 4. 데이터와 결과

- KOSIS 응답을 내부 리스트로 표준화한다: 기관·표 ID, 기준 시점, 구분별 코드·이름, 항목 코드·이름, 단위, 원래 값·부호 및 출처. 코드는 앞자리 0이 보존되도록 텍스트로 처리한다.
- 숫자와 미공표·결측·기타 부호를 구분한다. 미공표 또는 결측을 0으로 대체하지 않으며, 합산 대상에 그런 값이 있으면 불완전 집계로 표시한다.
- 사용자가 확인할 수 있는 **리스트형 시트와 행렬형 집계표 시트**를 새로 만든다. 집계표는 선택한 축 순서와 코드·명칭을 표시하고, 합계는 세부값이 중복되지 않도록 처리한다.
- 각 결과에 표 이름·기관·ID·분류 개정판·기준 시점·조회 일시·항목·단위·선택 조건·원자료 표 링크를 기록한다.
- 행·열 조합이 동일한 자료를 합산하기 전에 중복 요청에 따른 중복인지 확인한다. 의미 있는 하위 범주의 합산은 사용자가 명시한 경우에만 수행한다.
- Excel 행·열 제한과 예상 메모리 사용량을 검사한다. 큰 결과는 배열과 적정 크기 묶음으로 처리하고, 불가능한 출력은 생성 전에 설명한다.
- 결과 시트는 새 이름으로 만들고 원본 데이터를 보존한다. 취소·오류 시 이번 실행에서 만든 미완성 시트만 정리하고 기존 시트와 Excel 상태를 복구한다.

## 5. 시험 및 인수 기준

1. 세 종류의 대상 통계표와 개정판의 메타정보·실제 표를 대조하고 기관, 연도, 코드, 명칭, 단위와 범위를 확인한다.
2. 전국 기본값, 시도·시군구 선택, 산업 계층 다중 선택·검색, 코드 앞자리 0 보존, 상·하위 중복 경고를 검증한다.
3. 인구의 성별·1세별 조회, 사용자 연령구간 경계·중복·누락, 100세 이상 등 실제 제공되는 최상위 범주를 검증한다.
4. 사업체수와 종사자수를 혼동하지 않고 두 표의 구분을 선택·출력하는지 확인한다. 표가 제공하지 않는 지역·분류는 제공하지 않는다.
5. 리스트와 행렬의 같은 조합·합계가 일치하고 표본설계 미리보기에서 정확한 축과 숫자 영역을 선택할 수 있는지 확인한다.
6. 통계부호·결측, 0, API 오류, 인증 오류, 빈 응답, 요청 제한, 분할 조회의 중복·누락, 취소와 재시도를 시험한다. 원본과 기존 결과는 변경되지 않아야 한다.
7. 실제 Excel에서 UserForm의 화면 잘림, 마우스·키보드 조작, 진행률·취소, 보호된 XLAM을 검사한다. API 테스트는 공식 KOSIS 서버에만 요청하고 키를 기록하지 않는다.
8. 한글 원본 UTF-8 및 VBA 가져오기 인코딩, 한국어 깨짐, 전체 회귀 테스트, 배포 파일 키 누출, `git diff --check`, 설명서·패치노트를 확인한다.

## 6. 확인할 사항

- 표별 산업분류 개정판과 시점별 실제 수록 항목, `DT_1K52D*`/`DT_1K52F*`의 차이 및 세부 제공 범위.
- 주민등록인구 표의 수록 주기와 최상위 연령 범주, 인구 종류의 정확한 의미.
- 일반 API의 현행 조회 제한·호출 제한과 분할 결과의 안정성. 대용량 API는 별도 등록이 필요할 수 있으므로 일반 분할 조회와 혼동하지 않는다.
- 기존 표본설계 마법사와의 구체적 데이터 계약 및 취소 시 결과 복구. 이 항목들이 검증되기 전까지 자동 연계를 완료했다고 표시하지 않는다.
