# 데이터 편집 매크로 툴킷 1.2.0

## 주요 변경

- 하나의 거대한 VBA 파일을 데이터 정리, 기업명, 주소, API, 이상치, SPSS, 명부, 표본, 시트 통합 영역의 기능별 모듈로 나눴습니다.
- 개발용 XLSM과 배포용 XLSM/XLAM이 동일한 모듈 목록으로 만들어지도록 빌드 절차를 통일했습니다.
- 배포 파일 네 개를 저장한 뒤 VBA 잠금, API 인증정보 제거, 컴파일 스모크 테스트를 모두 다시 확인합니다.
- 기존 취소·오류 롤백, 대용량 배열 처리, 리본 메뉴와 사용자 기능은 그대로 유지합니다.

## 사용 방법

- 설치와 사용 방법은 이전 버전과 같습니다. `DataEditingMacroToolkit_latest.xlam`을 Excel 추가 기능으로 등록하면 됩니다.
- VBA 소스를 관리하거나 검토할 때는 `src` 폴더의 BAS 파일 전체를 함께 사용해야 합니다.
- 배포 파일에는 API 키가 포함되지 않습니다. API 기능을 처음 사용할 때 사용자 PC에서 키를 다시 설정해야 합니다.

## 수정된 문제

- 단일 VBA 파일과 단일 파일 가져오기에 묶여 있던 빌드·배포 구조를 기능별 모듈 기준으로 수정했습니다.
- 개발용 XLSM과 배포용 XLSM/XLAM의 VBA 모듈 구성이 달라질 수 있던 경로를 하나로 통일했습니다.

## 주의사항

- 기능별 자동 회귀 테스트
- VBA 프로젝트 다중 모듈 가져오기 및 컴파일 스모크 테스트
- XLSM/XLAM 산출물 일치 검사
- VBA 프로젝트 암호 보호와 API 인증정보 제거 검사
- 한글 깨짐 및 Git 공백 오류 검사
