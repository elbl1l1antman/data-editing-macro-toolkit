# 데이터 편집 매크로 툴킷 1.1.50

## 주요 변경

- 조회 수식 결과를 값으로 붙여넣은 뒤 남는 빈 문자열을 실제 빈셀로 바꾸는 `수식 빈값 정리` 기능을 추가했습니다.
- Excel의 텍스트 상수 필터를 먼저 사용해 전체 범위를 불필요하게 순회하지 않습니다.

## 사용 방법

1. `XLOOKUP`, `VLOOKUP` 등의 결과를 값으로 붙여넣습니다.
2. 정리할 범위를 선택합니다.
3. `값 정리 > 수식 빈값 정리` 또는 리본의 `수식 빈값 정리`를 실행합니다.
4. 확인창의 안내를 읽고 실행합니다.

## 수정된 문제

- 화면에는 비어 보이지만 `COUNTA`, 필터, 후속 수식에서 값이 있는 셀로 취급되던 길이 0 문자열을 실제 빈셀로 정리할 수 있습니다.

## 주의사항

- 선택 범위를 제자리에서 수정하므로 실행 전 대상 범위를 확인하세요.
- 실제 수식 셀, 숫자 `0`, 일반 텍스트, 공백 문자가 들어 있는 셀은 유지합니다.
- 공백 문자까지 지우려면 별도의 공백 정리 기능을 사용해야 합니다.
