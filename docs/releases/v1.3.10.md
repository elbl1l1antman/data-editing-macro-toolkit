# 버전 1.3.10

## 주요 변경

- KOSIS 모집단 결과의 값이 숫자로 저장됩니다. `KOSIS_리스트`의 값 열과 `KOSIS_집계표` 본문을 그대로 합계나 계산에 사용할 수 있습니다.
- KOSIS 연령구간 입력에 오류가 있거나 지정하지 않은 연령 경고에서 `아니요`를 누르면, 작업이 끝나지 않고 입력한 구간을 다시 수정하는 창이 열립니다.
- SPSS 보기 열 삭제에서 `계` 머리글이 여러 열에 병합된 표는 일부만 지우지 않고 건너뛴 뒤 완료 메시지에 표시합니다.

## 사용 방법

사용 방법은 이전과 같습니다. KOSIS 자료는 데이터 툴킷의 `표본설계` > `KOSIS 모집단`에서, 보기 열 삭제는 `SPSS 표 정리` > `보기 열 삭제`에서 실행합니다.

## 수정된 문제

- KOSIS 결과 시트의 숫자가 텍스트로 저장되어 SUM 결과가 0이 되거나 "텍스트로 저장된 숫자" 표시가 나타나던 문제를 수정했습니다. 코드·시점·명칭 열은 앞자리 0을 지키기 위해 계속 텍스트로 저장하며, 통계부호와 `자료 없음`도 텍스트로 남습니다.
- KOSIS 연령구간 오류나 미지정 연령 경고에서 `아니요`를 누르면 앞서 고른 시점·항목·지역이 모두 사라지고 작업이 끝나던 문제를 수정했습니다.
- 주민등록인구에서 직접 연령구간을 만든 뒤 처음 단계로 돌아가 사업체 통계표를 고르면, 이전 연령 경고가 확인창과 `KOSIS_검토` 시트에 남던 문제를 수정했습니다.
- SPSS 보기 열 삭제에서 `계` 머리글이 N·% 두 열처럼 여러 열에 병합되어 있으면 한 열만 지워지고도 삭제된 것으로 표시되던 문제를 수정했습니다.
- SPSS 보기 열 삭제 완료 메시지의 `삭제: 표 N개`에 병합 셀 때문에 건너뛴 표까지 포함되던 문제를 수정했습니다.
- 1.3.9부터 배포 폴더(`release/latest`, `release/v버전`)에는 설치용 XLAM, 패치노트, manifest만 포함합니다. 이전 배포에서 남아 있던 1.3.5 시점의 XLSM·BAS 파일을 정리했습니다.
- README와 사용자 메뉴얼을 현재 리본 구성에 맞게 정리했습니다. 메뉴얼 앞부분에 흩어져 있던 기능 설명을 해당 리본 그룹으로 옮기고, `통합 실행`, `행정동 양식/법정동 양식`, `행정구역 분해`, `전화번호 검사` 설명을 추가했습니다.

## 주의사항

- 이번 수정은 자동 테스트를 보강했으며, Excel에서 KOSIS 조회와 SPSS 보기 열 삭제의 전체 흐름은 배포 전에 다시 확인해야 합니다.
- KOSIS 조회에서 요청 묶음 하나가 자료를 전혀 돌려주지 않으면(폐지·개편된 시군구 등) 전체 조회가 실패할 수 있습니다. 이때는 지역이나 시점을 나누어 조회하세요.
- SPSS 보기 열 삭제는 머리글 행에 숫자(보기 코드, 연도 등)가 있으면 그 행부터 자료로 보고, 그 아래의 `계`는 찾지 않습니다.
- `Q`로 시작하는 제목의 표는 보기 열을 지운 뒤 제목 아래 머리글 셀이 하나만 남으면 새 목차에서 빠질 수 있습니다. 목차를 확인하세요.
