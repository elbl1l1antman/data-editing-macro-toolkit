# 데이터 편집 매크로 툴킷 1.3.1

## 주요 변경

- 버전 정보 창에 현재 버전의 최근 업데이트를 표시합니다. 내용은 배포 패치노트에서 자동으로 가져옵니다.
- DART 기업개황과 사업보고서 기준 별도 매출액·직원현황 조회를 이용할 수 있습니다.

## 사용 방법

- `데이터 툴킷` 탭의 `정보` > `버전 정보`에서 최신 변경사항을 확인합니다.
- `DART 기업정보`에서 인증키를 설정하고 기업명을 선택해 조회할 수 있습니다.

## 수정된 문제

- 버전 정보 창이 오래된 기본 기능만 표시하던 문제를 수정했습니다.

## 주의사항

- 업데이트 요약은 패치노트의 주요 변경 항목 중 앞부분을 표시합니다. 전체 내용은 해당 버전의 패치노트를 확인하세요.
- DART 매출액은 별도·개별 재무제표 API 기준이며 정정 공시 및 원문 대조는 별도로 필요합니다.
