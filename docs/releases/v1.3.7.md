# 버전 1.3.7

## 주요 변경

- 세 개의 연속된 전화번호 열을 선택해 하이픈이 포함된 하나의 새 열로 합치는 기능을 추가했습니다.
- 원본 세 열은 그대로 두며, 빈 부분이나 숫자 외 문자가 있는 행은 확인 대상으로 표시합니다.

## 사용 방법

데이터 툴킷에서 `전화번호 세 열 합치기`를 누르고 머리글을 제외한 세 열을 선택합니다.

## 주의사항

숫자로 저장하는 과정에서 이미 사라진 앞자리 0은 추정해 복원하지 않습니다. 원본 데이터를 확인하세요.

전화번호 조합 단위 테스트는 통과했으나, 실제 Excel에서 범위 선택부터 결과 생성까지의 전체 흐름은 아직 검증되지 않았습니다. 먼저 복사본에서 확인하세요.
