# 데이터 편집 매크로 툴킷 1.3.3

## 주요 변경

- SPSS 표에서 `■ 주력 사업`처럼 왼쪽에 표시된 병합 배너 묶음을 탐지하고 재구성할 수 있습니다.
- 배너 목록에서 위·아래 버튼으로 묶음 순서를 이동할 수 있습니다.
- DART 고유번호 목록은 계속 로컬에 저장되며 갱신 및 6개월 경과 안내를 지원합니다.

## 사용 방법

1. 집계표가 포함된 통합문서에서 `SPSS 표 정리` > `표/배너 재구성`을 실행합니다.
2. 배너를 선택해 `위로`·`아래로` 이동하거나 `삭제/복원`을 눌러 삭제 상태를 지정합니다.
3. 새 표와 목차 시트에서 결과를 확인합니다. 원본 시트는 유지됩니다.

## 수정된 문제

- B열의 `■` 표시 배너를 찾지 못하던 문제를 수정했습니다.
- 이동할 배너를 선택한 것만으로 삭제 대상이 되던 문제를 수정했습니다.
- 표 사이 구분 행이 이동된 배너 안에 섞일 수 있던 문제를 수정했습니다.

## 주의사항

- 같은 이름의 배너에 선택한 순서와 삭제 상태가 공통 적용됩니다.
- 표 위쪽의 표식 없는 응답 항목 열은 자동 배너로 취급하지 않습니다. 재구성한 표의 값을 확인하세요.
