# 데이터 편집 매크로 툴킷 개발 명세서 v1.1

작성일: 2026-06-10
기준 버전: 1.0.10
대상 파일: `src/MacroToolkit.bas`, `scripts/publish_release.ps1`

## 1. 전체 코드 리뷰 요약

현재 툴킷은 단순 데이터 클리닝 매크로에서 다음 기능군을 가진 Excel 추가기능으로 확장되었다.

- 값 정리: 텍스트 숫자 변환, 전화번호 정리, 대시 제거, 기업체명/사업체명 정리
- 주소/검색: 주소 유형 판별, 주소 체계 분리, 행정구역 분해, 네이버 지역검색, 행정동 마스터 양식
- 사업자등록: 번호 병합, 대시 제거, 공공데이터포털 상태조회, 반환 필드 선택
- 이상치 탐지: 범위 선택, 헤더 검토, Q1/Q3 검토열, 조건부 서식, 기초통계량표
- SPSS 표 정리: 목차 생성, 표/배너 재구성, 세로 배너 삭제, 메타 추출
- 명부 품질: 품질 진단, 중복 탐지, 업체명 매칭, 전화번호 검사

기능 범위가 충분히 넓어졌기 때문에 앞으로는 "기능 추가"와 함께 "사용성/안정성 공통 기반"을 계속 개선해야 한다.

## 2. 우선 개선 사항

### 2.1 모듈 분리

현재 `MacroToolkit.bas`가 6,000줄을 넘는 단일 모듈이다. 기능 추가 속도는 빠르지만, 컴파일 오류 위치 추적과 중복 함수 관리가 어려워진다.

개선 방향:
- `src/modules/` 폴더를 만들고 기능군별 `.bas` 소스를 분리한다.
- 예: `Core.bas`, `DataCleanup.bas`, `AddressTools.bas`, `BusinessNoTools.bas`, `NaverLocalTools.bas`, `OutlierTools.bas`, `SpssTableTools.bas`, `RosterQualityTools.bas`, `SampleDesignTools.bas`
- 배포 스크립트는 여러 `.bas` 파일을 가져와 XLAM에 삽입하도록 확장한다.
- 기존 단일 `MacroToolkit.bas`는 릴리스 호환용 통합 산출물로만 유지한다.

우선순위: 높음

### 2.2 공통 작업 래퍼 적용 확대

일부 기능은 `Application.ScreenUpdating`, `Calculation`, `EnableEvents`를 직접 제어하고, 일부 기능은 공통 래퍼를 사용한다. 오류가 발생하면 Excel 상태 복구가 기능별로 다르게 처리될 수 있다.

개선 방향:
- 모든 쓰기 작업은 `Toolkit_BeginOperation` / `Toolkit_EndOperation` 기반으로 통일한다.
- API 작업은 진행률 표시, 취소 불가 안내, 실패 로그 기록을 표준화한다.
- 오류 메시지는 사용자용 요약과 개발용 상세 로그를 분리한다.

우선순위: 높음

### 2.3 UserForm 기반 입력 마법사 확대

아직 많은 기능이 `InputBox` 번호 입력 방식이다. 빠르지만 선택지가 많아질수록 실수 가능성이 커진다.

개선 방향:
- 통합 실행 버튼은 기능군별 UserForm 런처로 교체한다.
- 범위 선택, 헤더 여부, 출력 위치, 처리 옵션을 한 화면 또는 단계형 마법사로 받는다.
- 명부 품질, 이상치 탐지, SPSS 표 재구성, 향후 표본설계 기능부터 우선 적용한다.

우선순위: 높음

### 2.4 외부 API 응답 파싱 안정화

사업자등록 API와 네이버 지역검색 API는 현재 문자열 기반 JSON 추출을 사용한다. 응답 구조가 단순할 때는 충분하지만, 특수문자/중첩 구조/빈값에서 취약할 수 있다.

개선 방향:
- VBA JSON 파서를 내장하거나 최소한 공통 JSON 추출 유틸을 별도 모듈로 분리한다.
- API별 status, errorCode, message, data 배열 처리 로직을 표준화한다.
- 실패 시 `_MacroToolkit_Log`에 요청 대상, HTTP 상태, 응답 일부, 실패 원인을 기록한다.

우선순위: 중상

### 2.5 성능 최적화

데이터가 큰 경우 셀 단위 반복이 Excel을 멈춘 것처럼 보이게 한다.

개선 방향:
- 값 정리, 주소 분리, 품질 진단, 표본할당은 Range 값을 배열로 읽고 배열로 한 번에 쓰는 방식을 우선 사용한다.
- 조건부 서식과 서식 복사는 최소 범위에만 적용한다.
- API 호출 기능은 진행률 폼과 상태바를 계속 유지하고, 캐시 적중률을 결과에 표시한다.

우선순위: 중상

### 2.6 회귀 테스트 체계

현재는 실제 Excel 실행 테스트 중심이다. 기능이 많아져서 한 기능 수정이 다른 기능에 영향을 줄 수 있다.

개선 방향:
- `tests/fixtures/`에 작은 샘플 파일을 기능군별로 둔다.
- 배포 전 체크리스트를 스크립트화한다.
- 최소 확인 항목: VBA 모듈 삽입 여부, 리본 XML 생성 여부, 버전 문자열, 주요 Public Sub 존재 여부, manifest 생성 여부.

우선순위: 중상

## 3. 신규 개발 후보

대화 기록과 현재 툴킷 성격을 기준으로 신규 개발 가치가 높은 기능은 다음과 같다.

1. 표본설계/표본할당 도구
2. 조사 명부 프레임 진단: 중복률, 주소 누락률, 전화번호 유효률, 지역/업종 분포 요약
3. 조사 진행률 관리표 생성: 목표 표본 대비 회수, 쿼터 미달/초과, 일별 진행률
4. 가중치 산출 보조: 모집단 구성비와 표본 구성비 비교, 기본 설계가중치 계산
5. 코드북/변수목록 생성: 원자료 첫 행과 값 범위를 바탕으로 변수명, 라벨, 결측 후보 정리
6. SPSS 표 후처리 고도화: 표 제목/배너/문항번호 패턴 학습형 탐지, 메타 검토 시트 생성
7. API 작업 큐 관리: 긴 API 작업을 배치 단위로 쪼개고 실패 건만 재시도

가장 먼저 구현할 신규 기능은 표본설계/표본할당 도구가 적합하다. 사용자의 조사 실무 흐름과 기존 명부 품질/주소/업종/지역 기능이 자연스럽게 연결된다.

## 4. 표본설계/표본할당 기능 명세

### 4.1 목표

모집단 정보를 기반으로 종사자 규모, 성별, 연령, 업종, 지역 등 쿼터 변수를 지정하고 목표 표본 수를 입력하면, 선택한 배분 방식에 따라 최종 표본할당표를 생성한다.

### 4.2 리본 UI

새 리본 그룹:
- 그룹명: `표본설계`

버튼:
- `설계 시트 생성`
- `할당 계산`
- `쿼터 점검`
- `진행률 관리표`

통합 실행 런처에는 `표본설계` 항목을 추가한다.

### 4.3 생성 시트

`설계 시트 생성` 실행 시 다음 시트를 만든다.

1. `표본설계_입력`
2. `표본설계_할당결과`
3. `표본설계_검토`
4. 선택 사항: `표본설계_진행관리`

기존 시트가 있으면 덮어쓰기 여부를 묻고, 덮어쓰지 않으면 고유 이름을 붙인다.

### 4.4 입력 시트 구조

`표본설계_입력`에는 다음 영역을 둔다.

#### A. 기본 설정

필드:
- 프로젝트명
- 조사명
- 목표 표본 수
- 최소 셀 표본 수
- 최대 셀 표본 수
- 반올림 방식
- 잔여 표본 배정 방식
- 배분 방식

배분 방식:
- 단순 비례 배분
- 제곱근 비례 배분
- 멱배분
- 균등 배분
- 사용자 지정 가중 배분

멱배분 설정:
- 지수 alpha 입력
- 기본값: 0.5
- alpha = 1이면 단순 비례
- alpha = 0.5이면 제곱근 비례
- alpha = 0이면 균등 배분

#### B. 모집단 표

필수 열:
- 쿼터ID
- 지역
- 업종
- 종사자규모
- 성별
- 연령
- 모집단수

선택 열:
- 우선배정여부
- 최소표본
- 최대표본
- 사용자가중치
- 비고

쿼터 변수는 비워둘 수 있다. 예를 들어 성별/연령을 쓰지 않는 설계에서는 해당 열을 비워도 된다.

#### C. 쿼터 사용 설정

체크 항목:
- 지역 사용
- 업종 사용
- 종사자규모 사용
- 성별 사용
- 연령 사용
- 사용자 지정 열 사용

향후 UserForm에서는 체크박스로 구현한다.

### 4.5 할당 계산 로직

입력:
- 각 셀의 모집단수 `N_i`
- 목표 표본 수 `n`
- 배분 방식
- 최소/최대 표본 제약

공통 전처리:
- 모집단수가 숫자가 아니거나 0 이하인 행은 검토 시트에 기록하고 계산에서 제외한다.
- 같은 쿼터 조합이 중복되면 합산 또는 오류 처리 중 사용자가 선택한다.
- 목표 표본 수가 유효하지 않으면 실행을 중단한다.

단순 비례:
- `raw_i = n * N_i / sum(N)`

제곱근 비례:
- `raw_i = n * sqrt(N_i) / sum(sqrt(N))`

멱배분:
- `raw_i = n * (N_i ^ alpha) / sum(N_i ^ alpha)`

균등 배분:
- `raw_i = n / cell_count`

사용자 지정 가중:
- `raw_i = n * weight_i / sum(weight)`

정수화:
- 기본 할당은 `floor(raw_i)`로 계산한다.
- 잔여 표본은 소수점 잔차가 큰 셀부터 1개씩 배정한다.
- 최소표본/최대표본 제약이 있으면 1차 배정 후 보정한다.
- 보정 후 총합이 목표 표본 수와 다르면 검토 시트에 경고를 남긴다.

### 4.6 출력 시트 구조

`표본설계_할당결과` 열:
- 쿼터ID
- 지역
- 업종
- 종사자규모
- 성별
- 연령
- 모집단수
- 모집단비율
- 배분방식
- 원시할당
- 최종할당
- 표본비율
- 설계효과 검토값
- 최소/최대 제약 적용 여부
- 비고

서식:
- 헤더 고정
- 총계 행 추가
- 목표 표본 수와 최종할당 합계 비교
- 최종할당 0인 셀 강조
- 최소표본 미달 또는 최대표본 초과 보정 셀 강조

### 4.7 검토 시트

`표본설계_검토`에는 다음을 출력한다.

- 총 모집단 수
- 목표 표본 수
- 최종 배정 표본 수
- 쿼터 셀 수
- 최종할당 0인 셀 수
- 최소표본 보정 건수
- 최대표본 보정 건수
- 제외된 행 목록
- 중복 쿼터 목록
- 모집단 비중 대비 표본 비중 차이가 큰 상위 셀

### 4.8 진행률 관리표

선택 기능으로 `표본설계_진행관리`를 만든다.

열:
- 쿼터ID
- 지역
- 업종
- 종사자규모
- 성별
- 연령
- 최종할당
- 회수
- 부족
- 초과
- 달성률
- 상태

상태:
- 미착수
- 진행중
- 미달
- 충족
- 초과

조건부 서식:
- 미달: 노랑
- 충족: 초록
- 초과: 빨강

### 4.9 사용자 흐름

1. 사용자가 `표본설계 > 설계 시트 생성` 클릭
2. 툴킷이 입력/결과/검토 시트 생성
3. 사용자가 모집단 표와 목표 표본 수 입력
4. 사용자가 `할당 계산` 클릭
5. UserForm에서 배분 방식, 쿼터 변수, 최소/최대 제약 적용 여부 선택
6. 툴킷이 할당결과와 검토 시트 생성
7. 필요하면 `진행률 관리표` 생성

### 4.10 예외 처리

- 목표 표본 수가 비어 있음: 실행 중단
- 모집단수 합계가 0: 실행 중단
- 모든 쿼터 변수가 비어 있음: 전체 단일 셀로 계산할지 확인
- 중복 쿼터: 합산 또는 중단 선택
- 최소표본 제약 합계가 목표 표본 수보다 큼: 실행 중단
- 최대표본 제약 합계가 목표 표본 수보다 작음: 실행 중단
- 결과 시트가 이미 있음: 덮어쓰기/새 이름 선택
