# 버전 1.3.9

## 주요 변경

- SPSS 표 정리에 `보기 열 삭제`를 추가했습니다. 모든 표의 머리글에서 `계`처럼 이름이 정확히 같은 보기 열을 한 번에 삭제합니다.
- 각 표의 행 범위 안에서만 셀을 지우고 오른쪽 열을 당겨 붙이므로, 위아래 다른 표의 열 배치는 바뀌지 않습니다.

## 사용 방법

데이터 툴킷의 `SPSS 표 정리`에서 `보기 열 삭제`를 누르거나 `SPSS 표 도구`에서 5번을 선택합니다. 삭제할 보기 이름을 입력하면(기본값 `계`, 여러 개는 `계, 합계`처럼 쉼표로 구분) 대상 표와 열 수를 확인한 뒤 `SPSS_보기삭제` 시트와 새 `SPSS_목차` 시트를 만듭니다. 원본 시트는 그대로 유지됩니다.

## 수정된 문제

- `세로 배너 삭제`와 같은 방식으로 목차가 여러 표 시트를 가리킬 때 정리할 시트를 고르도록 표 선택 로직을 공통으로 정리했습니다. 기존 동작은 바뀌지 않습니다.

## 주의사항

- `총계`, `▶합계◀`, `▶평균◀`처럼 이름이 다른 열과 표 본문의 행 이름 `계`는 삭제하지 않습니다.
- 삭제한 열에 걸친 제목·배너 병합 셀은 한 칸 줄여 다시 병합합니다. 병합 셀이 표 범위를 넘어 안전하게 지울 수 없는 열은 건너뛰고 완료 메시지에 표 이름을 표시합니다.
- 실제 SPSS 집계표(`계` 열 52개)로 전체 흐름을 확인했습니다. 결과 시트에서 표 끝 열과 병합 상태를 한 번 확인하세요.
