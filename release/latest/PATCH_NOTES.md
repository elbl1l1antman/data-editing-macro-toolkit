# 데이터 편집 매크로 툴킷 1.3

## 주요 변경

- OpenDART 기업정보 조회를 추가했습니다. 기업개황과 지정 사업연도의 별도 매출액·직원 수를 새 시트로 가져옵니다.
- 기업명 외에 DART 고유번호 8자리와 종목코드 6자리도 입력할 수 있습니다.

## 사용 방법

1. `DART 기업정보` > `인증키 설정`에서 OpenDART 인증키를 입력합니다.
2. `기업정보 조회`에서 기업명이 있는 범위, 제목 여부, 사업연도를 지정합니다.
3. 생성된 결과 시트의 계정명·통화·직원 집계 기준과 검토 사항을 확인합니다.

## 수정된 문제

- 동명 회사는 임의로 선택하지 않고 확인이 필요한 항목으로 표시합니다.
- 직원현황의 합계와 상세행을 함께 더하지 않도록 처리합니다.

## 주의사항

- OpenDART 공시대상과 제공 자료에 한해 조회합니다. 데이터가 없으면 0이 아닌 빈칸으로 남깁니다.
- 매출은 사업보고서의 별도 재무제표 API 기준입니다. 연결 전환, 정정공시 대조, 원문 파싱은 제공하지 않으므로 중요한 수치는 원문을 확인하세요.
- 결과 금액과 직원 수는 숫자 정밀도 유지를 위해 텍스트로 기록합니다. 네트워크 요청 중 취소는 응답 또는 시간 초과 후 처리됩니다.
- 인증키는 Windows 사용자 설정에만 저장되며 배포 파일에 포함되지 않습니다.
