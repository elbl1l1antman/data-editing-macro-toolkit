# 데이터 편집 매크로 툴킷 1.3.2

## 주요 변경

- DART 고유번호 목록을 최초 조회 시 로컬에 저장하고 이후 조회에서 재사용합니다.
- `고유번호 갱신` 버튼을 추가하고 목록이 6개월 이상 경과하면 선택 안내를 표시합니다.

## 사용 방법

- 처음 기업정보를 조회할 때 목록이 자동으로 저장됩니다.
- 최신 목록이 필요하면 `DART 기업정보` > `고유번호 갱신`을 누릅니다.
- 6개월 경과 안내에서는 갱신 후 조회하거나 기존 목록을 사용하거나 취소할 수 있습니다.

## 수정된 문제

- 매번 전체 고유번호 목록을 내려받던 불필요한 반복 요청을 없앴습니다.
- 갱신 실패나 취소 시 이전 목록을 보존합니다.

## 주의사항

- 목록은 현재 Windows 사용자에만 저장되며, 다른 PC나 계정에서는 최초 다운로드가 필요합니다.
- 기업개황, 매출액 및 직원현황은 최신 정보를 위해 조회 시 API를 사용합니다.
