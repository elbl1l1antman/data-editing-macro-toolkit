## 사용 방법

표본설계는 `설계 시트 생성`으로 시작합니다. 예시의 `기본 예시로 연습하기`를 누르고 입력 시트의 `할당 계산`에서 단순 비례를 선택하면 100 / 50 / 30, 합계 180개로 배분됩니다. 실제 작업은 이동 링크를 이용하고, 연습했다면 예시 3행을 모두 삭제한 뒤 실제 모집단수와 목표 표본수로 바꿉니다. 집계표 방식은 10행부터 실제 표를 붙여넣습니다. 기존 입력·결과는 시트 생성만으로 초기화하지 않습니다.

1. `값 정리 > 기업/사업체명 정리`에서 회사명 범위를 선택합니다.
2. 본사·지점 등의 표기만 정리하려면 `사업장 표기 제거`를 선택합니다. `신한은행본점 → 신한은행`, `국민은행본사 → 국민은행`, `삼성증권제1지점 → 삼성증권`으로 정리됩니다.
3. 지명도 없애려면 `지명까지 함께 제거 (행정동 기준)`를 선택합니다. 두 항목을 함께 켠다면 지명 제거가 먼저 실행되도록 선택합니다.
4. 결과 복사본을 검토합니다. `한빛판교공장`, `한빛청주사업소`, `한빛세종대로지점`은 지명 제거를 선택하면 `한빛`이 됩니다.
5. 참고 지명을 바꾸려면 `행정동 양식`으로 현재 통합문서의 `행정동_마스터`를 수정합니다. 따로 만들지 않으면 XLAM 내장 자료를 사용합니다.

## 수정된 문제

- 기존 본점/지점 제거만으로 판교·청주 같은 지명이 남거나 공장·사업소·영업소가 제거되지 않던 경우를 별도 규칙으로 처리합니다.
- 반쪽 괄호 `주)`와 전각 공백이 들어간 법인표기를 인식하지 못하던 문제를 수정했습니다.
- 새 체크박스를 포함한 옵션 창 경계와 실제 클릭 순번을 확인했습니다.

## 주의사항

- SPSS 자동 탐지는 제목이 A/B열에 있는 알려진 형식과 구조가 분명한 세로 배너를 우선합니다. 표식 없는 가로 응답 항목과 모호한 세로 배너는 자동 삭제하지 않으므로 실행 전 후보를 확인하세요. 존재하지 않는 시트의 링크는 복구하지 않습니다.
- 사업체명 보존 정리는 같은 기업 여부를 판정하지 않습니다. 출처별 식별번호 대조, 전년도 기업체명 연결 및 검토 상태 열은 제공하지 않으므로 결과를 원본과 함께 검토하세요.
- 지명에 대로·로·길을 붙인 형태도 인식하지만 실제 도로명 존재 여부를 확인하는 주소 API 기능은 아닙니다.
- 자료에 없는 지명을 추측해 제거하지 않으며, 이름 전체를 공란으로 만들지 않습니다. 지역명이 실제 상호에 포함될 수 있으므로 결과를 검토하세요.
- 500행 배열 처리와 원본 보존은 유지합니다. 행정동 자료는 실행마다 한 번만 읽습니다.
- 개발 중인 `자료 가져오기` 기능은 이번 배포에 포함하지 않습니다.
