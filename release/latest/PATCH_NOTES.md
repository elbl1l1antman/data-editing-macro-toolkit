# 버전 1.3.8

## 주요 변경

- 전화번호 세 열 합치기에서 숫자형 저장으로 사라진 지역번호·휴대전화·050 번호의 선행 0을 보완합니다.
- 복원할 수 없는 앞자리나 잘못된 자릿수는 원본을 유지하고 결과 열에 `확인 필요`로 표시합니다.

## 사용 방법

데이터 툴킷의 `값 정리`에서 `전화번호 세 열 합치기`를 누르고, 머리글을 제외한 앞자리·중간자리·끝자리 세 열을 선택합니다. 결과는 선택 범위 오른쪽에 새 열로 생성되며 원본 세 열은 그대로 유지됩니다.

## 수정된 문제

- 앞자리가 숫자로 저장되어 `2`, `10`, `507`처럼 0이 빠진 경우 합친 결과가 `2-123-4567`처럼 잘못 만들어지던 문제를 수정했습니다. 이제 `02-123-4567`, `010-1234-5678`, `0507-1234-5678`처럼 보완합니다.

## 주의사항

- 가운데나 끝부분에서 이미 사라진 0은 추정하지 않습니다. 원본과 결과를 확인하세요.
- 전화번호 조합 단위 테스트를 수행했으며, Excel 범위 선택부터 결과 생성까지의 전체 화면 흐름은 별도 검증이 필요합니다.
