# 데이터 편집 매크로 툴킷 1.2.7.1

## 주요 변경

- 리본의 접힌 기능 그룹을 각각 알아볼 수 있는 아이콘으로 구분했습니다.
- 이상치 탐지 등 Excel에서 표시되지 않던 버튼 아이콘을 교체했습니다.
- `지금 A1 정렬`을 별도 `시트 위치` 그룹으로 옮겼습니다.
- 사업자등록 상태조회 선택 창의 실행·취소 버튼이 잘리지 않도록 조정했습니다.

## 사용 방법

- Excel의 `데이터 툴킷` 탭에서 기능별 아이콘을 선택합니다.
- 모든 시트 위치를 바로 맞추려면 `시트 위치`의 `지금 A1 정렬`을 누릅니다.

## 수정된 문제

- 사업자등록 상태조회 창 아래쪽 버튼이 잘리는 문제를 수정했습니다.
- 일부 리본 아이콘이 표시되지 않던 문제를 수정했습니다.

## 주의사항

- 통합문서 닫을 때 자동 정렬하는 기능은 아직 제공하지 않습니다.
- 숨김 시트는 즉시 정렬에서 건너뜁니다.
