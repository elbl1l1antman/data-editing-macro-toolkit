# 버전 1.3.6

## 주요 변경

- KOSIS 주민등록인구와 전국사업체조사 자료를 선택해 모집단 자료로 가져오는 기능을 추가했습니다.
- 시점, 지역, 산업, 항목과 행렬 구성을 선택하고 코드와 이름을 함께 확인할 수 있습니다.
- 선택 도중 이전 단계로 돌아가 이미 확인한 조건을 수정할 수 있습니다.
- 자료를 리스트, 집계표, 검토 시트로 만들고 미공표 기호와 출처를 보존합니다.
- KOSIS 분류정보를 로컬에 보관하며 필요할 때 갱신할 수 있습니다.

## 사용 방법

데이터 툴킷의 표본설계 영역에서 KOSIS 인증키를 등록한 뒤 KOSIS 모집단을 실행하세요. 조회 후 검토 시트를 확인하고, 표본설계에 사용할 범위는 직접 선택합니다.

## 주의사항

- 인증키는 사용자의 Windows 설정에 저장하며 배포 파일에 포함하지 않습니다.
- 통계표에서 제공하지 않는 지역이나 연령은 추정하지 않습니다. 미공표·누락 값은 0으로 바꾸지 않습니다.
- 산업 상위·하위나 전국과 지역을 함께 선택하면 중복 가능성을 확인하세요.
- 인구표의 전체 사용자 화면 흐름과 표본설계 연계는 이번 릴리스에서 별도로 검증하지 않았습니다.
