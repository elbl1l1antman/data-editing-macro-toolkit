# 1.3.5

## 주요 변경
- 모집단 집계표 전체를 선택하면 구분과 모집단 영역을 자동으로 제안합니다.
- 상위 구분을 먼저 배분한 후 나머지 구분을 배분하는 2단계 설계와 중간 검토표를 추가했습니다.
- 새 표본설계 결과의 구분을 명부 열과 연결하여 층화 표본 추출에 활용할 수 있습니다.

## 사용 방법
1. 표본설계 메뉴의 집계표 마법사에서 자동 인식 또는 직접 지정을 선택하고 미리보기를 확인합니다.
2. 목표 표본과 배분 방식, 필요하면 2단계 구분과 각 단계의 방식을 지정합니다.
3. 표본 추출에서 생성한 설계 결과를 선택하고 명부 층화 열과 설계 구분을 연결합니다.

## 수정된 문제
- 모집단과 목표 표본이 혼재된 모호한 머리글은 자동 확정을 피합니다.
- 결과와 명부의 구분값, 목표 합계 또는 모집단 인원이 일치하지 않으면 자동 추출을 막고 확인을 요청합니다.

## 주의사항
- 자동 인식 결과의 소계와 범위는 사용자가 반드시 확인해야 합니다. 모호한 구조는 직접 지정하세요.
- 2단계 배분은 한 개 중간 구분을 지원하며 셀별 공통 최소·최대 조건은 단일 단계에서만 설정합니다.
- 결과는 표본 할당이며, 표본오차를 자동으로 보증하지 않습니다.
