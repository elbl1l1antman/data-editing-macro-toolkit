# 데이터 편집 매크로 툴킷 1.2.3

## 주요 변경

- 통신사 대표번호 접두어 15종을 명시적으로 인식합니다.
- 끝자리만 다른 복수 대표번호를 두 개의 전화번호로 분할합니다.

## 사용 방법

1. `데이터 툴킷 > 값 정리 > 전화번호 정리`에서 전화번호 범위를 선택합니다.
2. 8자리 휴대폰 변환 옵션을 선택하더라도 등록된 대표번호 접두어는 `####-####` 형식을 유지합니다.
3. `1588-12345` 또는 `1588-1234~5`가 있으면 `_정리1`, `_정리2` 열에서 분할 결과를 확인합니다.
4. 전화번호 검사에서는 해당 값을 `대표번호 복수 확인 필요`로 확인할 수 있습니다.

## 수정된 문제

- 8자리 휴대폰 변환 옵션을 사용할 때 대표번호까지 `010-XXXX-XXXX`로 바뀌던 문제를 수정했습니다.
- 한 셀에 끝자리만 다른 대표번호 두 개를 축약해 입력한 값을 분리할 수 없던 문제를 수정했습니다.

## 주의사항

- 대표번호 접두어는 `1588`, `1577`, `1899`, `1544`, `1644`, `1661`, `1566`, `1600`, `1670`, `1688`, `1666`, `1599`, `1877`, `1855`, `1800`입니다.
- 복수 대표번호 분할은 등록된 접두어와 숫자 9자리 구조를 모두 만족하고 마지막 두 숫자가 다를 때 적용합니다.
- 원본 열은 유지되며 복수 대표번호가 실제로 발견된 경우에만 두 번째 정리 결과 열을 추가합니다.
